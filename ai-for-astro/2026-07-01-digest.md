## 1. CORTEX: Token-Level Hallucination Detection in RAG via Comparative Internal Representations

- arXiv ID: `2606.31033`
- Authors: Kazuaki Furumai , Shuichiro Haruta , Kazunori Matsumoto , Daisuke Kamisaka
- Score: 9
- Link: https://arxiv.org/abs/2606.31033
- PDF: https://arxiv.org/pdf/2606.31033
- Subjects: Computation and Language (cs.CL)
- Reason: Token-level hallucination detection in RAG is directly relevant to building reliable LLM agents for literature review and data analysis in astronomy.

Short digest:
This paper proposes CORTEX, a token-level hallucination detection method for Retrieval-Augmented Generation (RAG). It compares internal representations of an LLM with and without retrieved documents to identify ungrounded tokens. For astronomy, this could be used to build reliable LLM agents that summarize literature or analyze data while flagging potential hallucinations. The method enables fine-grained localization of hallucinations, which is crucial for scientific accuracy. A limitation is that it requires access to the LLM's internal representations, which may not be available for all models, and it is tested on generic RAG benchmarks, not astronomical texts.

Full-text inspection checklist:
- Check if the method can be applied to domain-specific RAG systems (e.g., with astronomical literature or data).
- Look for the types of hallucinations detected and whether they correspond to common errors in scientific summarization.
- See if the post-processing smoothing step is robust to the longer spans typical in scientific texts.
- Check if the method requires specific model architectures or if it is model-agnostic.

## 2. One Reflection Is Not Enough: Self-Correcting Autonomous Research via Multi-Hypothesis Failure Attribution

- arXiv ID: `2606.31478`
- Authors: Jie Ma , Binfei Chu , Jie Gao , Jinlu Zhang , Yiwei Ma , Yi Tan , Jiayi Ji , Xiaoshuai Sun , Rongrong Ji
- Score: 9
- Link: https://arxiv.org/abs/2606.31478
- PDF: https://arxiv.org/pdf/2606.31478
- Subjects: Artificial Intelligence (cs.AI) ; Computer Vision and Pattern Recognition (cs.CV)
- Reason: This paper directly addresses automated scientific discovery with LLM agents, which is a core interest. It proposes a structured failure-recovery mechanism for research agents that could be applied to astronomical data analysis workflows, such as automated SED fitting or spectral analysis.

Short digest:
This paper tackles the problem of brittle failure recovery in autonomous research agents, where current methods rely on single free-form reflections that often lead to trial-and-error or loss of useful context. The core idea is Multi-Hypothesis Failure Attribution (MHFA), which treats failure recovery as a structured causal diagnosis: it generates multiple evidence-grounded explanations for a failure, evaluates their severity, and routes the verified root cause to the correct intervention level (hypothesis, experimental design, or implementation). The method also includes a grounded reporting mechanism that redacts hallucinated numbers. For astronomy, this could be transformative for automated data analysis pipelines: imagine an agent that attempts to fit a spectrum, fails, and systematically diagnoses whether the problem is a bad model, poor data quality, or a bug in the code, then corrects the appropriate component. A concrete workflow might involve using SAGE to autonomously analyze JWST spectra of high-redshift galaxies, where the agent writes code to perform SED fitting, detects failures (e.g., poor chi-squared), and automatically corrects the model or preprocessing steps. However, the paper's benchmark is on general scientific topics (e.g., physics, chemistry) and may not include astronomy-specific tasks, so the agent's performance on astronomical data is unknown. The method requires access to LLMs with coding capabilities and a sandboxed execution environment.

Full-text inspection checklist:
- Check if the benchmark includes any astronomy or astrophysics tasks, or if the method is demonstrated on data similar to astronomical spectra or images.
- Look for details on how the MHFA mechanism generates and evaluates multiple hypotheses, and whether it requires a predefined set of possible failure modes.
- Examine the grounded reporting mechanism to see if it can be adapted for astronomical results (e.g., ensuring reported fluxes are within realistic ranges).
- Check the code and reproducibility: is the system available and can it be run on custom astronomical datasets?

- Subjects: Computer Vision and Pattern Recognition (cs.CV)
- Reason: Satellite image synthesis with geospatial primitives is directly relevant to astronomical image generation and data augmentation for surveys.

Short digest:
This paper introduces TerraDiT-Ω, a unified spatial control framework for satellite image synthesis that generates imagery from any native geospatial primitive (polygons, polylines, bounding boxes, points). It uses Geometry-Aware Local Attention to inject geometric cues into the diffusion model's attention space. For astronomy, this could be used to generate synthetic astronomical images from catalog data or morphological annotations, aiding in data augmentation for surveys like JWST, Roman, or Euclid. The method supports controllable layouts and could be applied to tasks like land-cover segmentation, object detection, and scene classification, which have direct analogs in astronomy (e.g., source detection, morphology classification). A limitation is that the paper focuses on satellite imagery, and the geospatial primitives may need adaptation to astronomical coordinate systems and source shapes.

Full-text inspection checklist:
- Check if the method can generate images with point-like sources (stars, galaxies) or extended structures (nebulae, galaxy clusters).
- Look for the types of geospatial primitives used and whether they can be mapped to astronomical annotations (e.g., source positions, morphological masks).
- See if the synthetic data augmentation improves downstream performance on tasks analogous to astronomical classification or detection.
- Check if the code and weights are available and can be adapted for astronomical image generation.

- Reason: Directly applies flow matching to probabilistic inversion in geophysics, a method that could transfer to astronomical inverse problems like source reconstruction or parameter estimation.

Short digest:
This paper applies Flow Matching, a generative AI technique, to probabilistic inversion in geophysical settings, specifically seismic Full-Waveform inversion. It adapts the mathematical theory of Flow Matching to produce posterior distributions over velocity models given seismic data. The method is demonstrated on a simple 2D velocity model and the OpenFWI dataset. For astronomy, this is highly relevant because many astronomical problems are inverse problems (e.g., reconstructing galaxy properties from spectra, or mapping dark matter from lensing). Flow Matching could provide a principled way to sample from the posterior distribution, enabling uncertainty quantification. The main caveat is that the paper focuses on 2D seismic velocity models, and adapting the method to high-dimensional astronomical data (e.g., 3D maps, spectra) may require significant computational resources and architectural changes.

Full-text inspection checklist:
- Check if the Flow Matching architecture can handle high-dimensional outputs (e.g., images, spectra).
- Look for discussion of the computational cost of training and sampling.
- Examine the uncertainty quantification: does the posterior capture realistic uncertainties for astronomical applications?

## 5. ReGRPO: Reflection-Augmented Policy Optimization for Tool-Using Agents

- Authors: Binjie Zhang , Mike Zheng Shou
- Score: 8
- Link: https://arxiv.org/abs/2606.31392
- PDF: https://arxiv.org/pdf/2606.31392
- Subjects: Artificial Intelligence (cs.AI)
- Reason: Directly relevant to building LLM agents for scientific workflows, with a focus on tool use and recovery from failures, which is crucial for automated data analysis in astronomy.

Short digest:
This paper tackles the problem that tool-using AI agents often fail silently and cannot recover from errors. It introduces ReGRPO, a method that first collects examples of failures and their corrections, then uses reinforcement learning to jointly optimize the agent's reasoning about errors and its corrective actions. For astronomy, this could enable an agent that runs a photometric redshift pipeline, detects when a fit fails, and automatically tries a different SED template or flags the object for review. A concrete workflow would be an agent that ingests JWST NIRSpec spectra, calls a spectral fitting tool, and if the fit fails, reflects on the cause and retries with different parameters. A key caveat is that the method was tested on general vision-language benchmarks, so its performance on domain-specific scientific tools and data formats needs verification.

Full-text inspection checklist:
- Check if the failure trajectories and reflection triplets are grounded in realistic tool-use scenarios or synthetic tasks.
- Look for ablation studies showing whether the reflection-cost term is necessary to prevent over-reflection in a scientific context.
- Examine the tool suite used in experiments to see if it includes any scientific or data-analysis tools relevant to astronomy.

## 6. Calibration, Not Compilation: Detecting and Repairing Misspecified Probabilistic Programs Written by Language Models

- arXiv ID: `2606.31630`
- Authors: Jian Xu , Delu Zeng , John Paisley , Qibin Zhao
- Score: 8
- Link: https://arxiv.org/abs/2606.31630
- PDF: https://arxiv.org/pdf/2606.31630
- Subjects: Machine Learning (cs.LG)
- Reason: Directly addresses automated detection and repair of misspecified probabilistic programs, which is highly relevant for astronomical SED fitting, spectral fitting, and photometric redshift estimation where Bayesian models are common.

Short digest:
This paper addresses the problem that LLM-written probabilistic programs can compile and run but be statistically wrong (e.g., wrong likelihood, invalid priors). It proposes using Bayesian workflow diagnostics (posterior predictive checks, simulation-based calibration, sampler diagnostics) as a calibration oracle to detect and repair misspecified models. For astronomy, this is directly applicable to automated generation and validation of SED fitting models, spectral fitting codes, or photometric redshift models where correct statistical specification is critical. A concrete workflow would be using an LLM to write a Bayesian SED fitting model in NumPyro, then running the calibration oracle to check for misspecification before applying to real JWST data. A key caveat is that the reference-free detection achieves only 62-78% AUC, so manual verification of the calibration diagnostics is still needed.

Full-text inspection checklist:
- Look for the specific Bayesian workflow diagnostics used (R-hat, ESS, divergences, posterior predictive checks) and how they are combined into a detection score
- Check the repair loop implementation: how does the LLM receive calibration feedback and iteratively improve the model?
- Examine the 14 misspecification types and whether they cover common astronomical modeling pitfalls (e.g., wrong noise model, incorrect prior support for physical parameters)
