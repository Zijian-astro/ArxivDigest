## 1. ViDR: Grounding Multimodal Deep Research Reports in Source Visual Evidence

- arXiv ID: `2605.13034`
- Authors: Zhuofan Shi , Peilun Jia , Baoqin Sun , Haiyang Shen , Sixiong Xie , Yun Ma , Xiang Jing
- Score: 8
- Link: https://arxiv.org/abs/2605.13034
- PDF: https://arxiv.org/pdf/2605.13034
- Subjects: Computer Vision and Pattern Recognition (cs.CV) ; Information Retrieval (cs.IR)
- Reason: Multimodal deep research framework grounding reports in source figures; directly applicable to astronomical literature review and data analysis.

Short digest:
The paper asks how to generate long-form research reports that properly cite and use source figures, not just text. It presents ViDR, a framework that treats source figures as retrievable, interpretable, and verifiable evidence, building an evidence-indexed outline and refining noisy web images into structured evidence atoms. This is highly relevant for astronomy because astronomers often need to synthesize results from papers with figures (e.g., spectra, images, SEDs). An astronomer could use ViDR to automatically generate literature reviews that include relevant figures from JWST papers, with proper attribution. The framework also validates visual references to reduce hallucinations. A limitation is that it requires a large corpus of web images and may need adaptation for specialized astronomical figure formats (e.g., FITS files).

Full-text inspection checklist:
- Check how the framework handles figures with complex annotations (e.g., spectral lines, redshift markers) common in astronomy.
- Look for the evidence-indexed outline construction: does it require a pre-existing knowledge base or can it work with raw arXiv PDFs?
- Examine the VLM-based visual analysis component: which VLM is used, and is it fine-tuned on scientific figures?

## 2. It's not the Language Model, it's the Tool: Deterministic Mediation for Scientific Workflows

- arXiv ID: `2605.13245`
- Authors: Marios Adamidis , Danae Katrisioti , Yannis Tzitzikas , Emmanuel Stratakis
- Score: 8
- Link: https://arxiv.org/abs/2605.13245
- PDF: https://arxiv.org/pdf/2605.13245
- Subjects: Artificial Intelligence (cs.AI)
- Reason: Directly addresses reproducibility in scientific workflows using LLMs, which is a key concern for automated scientific discovery and research agents in astronomy.

Short digest:
This paper tackles the problem that LLMs produce non-reproducible results when queried repeatedly on the same scientific data. The core idea is 'typed mediation': instead of having the LLM generate analytical code, it orchestrates deterministic, pre-built tools that encode exact researcher procedures, guaranteeing identical outputs across runs. For astronomy, this is highly relevant because reproducible analysis is critical for JWST and survey data, where one might want to automate SED fitting or spectral analysis without variability. A concrete workflow would be using an LLM agent to call a deterministic photometric redshift code or spectral fitting tool, ensuring identical results every time. A key caveat is that the tools must be pre-built and ported from researcher procedures, which requires upfront effort and domain expertise. Before investing time, check whether the paper provides a generic framework or only instrument-specific examples, and whether the typed mediation pattern can be adapted to astronomical tools like CIGALE or Prospector.

## 3. Utility-Oriented Visual Evidence Selection for Multimodal Retrieval-Augmented Generation

- arXiv ID: `2605.13277`
- Authors: Weiqing Luo , Zongye Hu , Xiao Wang , Zhiyuan Yu , Haofeng Zhang , Ziyi Huang
- Score: 8
- Link: https://arxiv.org/abs/2605.13277
- PDF: https://arxiv.org/pdf/2605.13277
- Subjects: Computation and Language (cs.CL) ; Artificial Intelligence (cs.AI); Computer Vision and Pattern Recognition (cs.CV); Information Retrieval (cs.IR); Machine Learning (cs.LG)
- Reason: Directly addresses visual evidence selection for multimodal RAG, which is highly relevant to astronomical workflows combining images, spectra, and catalogs.

Short digest:
This paper addresses the problem that existing multimodal retrieval-augmented generation (RAG) methods select visual evidence based on semantic similarity, which may not be useful for downstream reasoning. The main idea is to reformulate evidence selection as maximizing information gain on the model's output distribution, using a training-free surrogate framework with lightweight multimodal models. For astronomy, this is highly relevant because it could enable RAG systems that retrieve the most useful JWST images, spectra, or catalog entries to answer scientific queries. A concrete workflow would be building a multimodal RAG system for a JWST survey where the model retrieves the most informative cutouts or spectra for a given question about a high-redshift galaxy. A key caveat is that the method is evaluated on general-domain benchmarks (MRAG-Bench, Visual-RAG), not on scientific or astronomical data. Before investing time, check whether the surrogate models used (lightweight multimodal models) can handle astronomical image formats (FITS, multi-band) and whether the framework can be adapted to domain-specific retrieval tasks.

## 4. Mixed neural posterior estimation for simulators with discrete and continuous parameters

- arXiv ID: `2605.13551`
- Authors: Jan Boelts , Cornelius Schröder , Jonas Beck , Jakob H. Macke , Michael Deistler , Daniel Gedon
- Score: 8
- Link: https://arxiv.org/abs/2605.13551
- PDF: https://arxiv.org/pdf/2605.13551
- Subjects: Machine Learning (cs.LG)
- Reason: This paper extends neural posterior estimation to mixed discrete/continuous parameter spaces, which is directly applicable to astronomical SED fitting and spectral fitting where parameters can be both continuous (e.g., redshift, metallicity) and discrete (e.g., galaxy type, AGN flag).

Short digest:
The paper addresses the limitation of neural posterior estimation (NPE) for simulators with mixed discrete and continuous parameters. The main idea is to use an inference network that factorizes the joint posterior into discrete and continuous components, combining an autoregressive classifier for discrete parameters with a generative model for continuous parameters. This matters for astronomy because many astronomical models (e.g., SED fitting, spectral fitting) have both discrete parameters (e.g., galaxy morphology class, AGN presence) and continuous parameters (e.g., redshift, stellar mass). I could imagine using this to perform Bayesian inference on JWST spectra of high-redshift galaxies, jointly estimating the probability of AGN vs. star-forming classification and continuous physical properties. A caveat is that the method requires a simulator that can generate mock data, which may be computationally expensive for complex astrophysical models.

Full-text inspection checklist:
- Look for the diagnostic tool to assess calibration of mixed posterior approximations.
- Check the toy examples and real-world simulators used for validation.
- See if the method is available in the sbi Python package and how to adapt it for custom simulators.
- Examine the autoregressive classifier architecture for discrete parameters.

## 5. VectorSmuggle: Steganographic Exfiltration in Embedding Stores and a Cryptographic Provenance Defense

- arXiv ID: `2605.13764`
- Authors: Jascha Wanger
- Score: 8
- Link: https://arxiv.org/abs/2605.13764
- PDF: https://arxiv.org/pdf/2605.13764
- Subjects: Cryptography and Security (cs.CR) ; Information Retrieval (cs.IR); Machine Learning (cs.LG)
- Reason: Directly addresses security of RAG systems using vector databases, which is relevant for building reliable retrieval-augmented generation tools for astronomy literature and data.

Short digest:
This paper addresses the problem of steganographic attacks on vector databases used in retrieval-augmented generation (RAG) systems, where an attacker can hide payload data inside embeddings. The main idea is to show that simple perturbations like rotation can evade anomaly detection, and propose a cryptographic provenance protocol (VectorPin) to ensure embedding integrity. For astronomy, this is important if you build a RAG system to retrieve papers or data—you need to trust that the embeddings haven't been tampered with. A concrete workflow would be using VectorPin to verify that embeddings of astronomical catalogs or literature are authentic. A key caveat is that the paper focuses on security, not on improving retrieval quality, and the protocol adds overhead.

Full-text inspection checklist:
- Check if the VectorPin protocol is compatible with common vector database APIs (e.g., FAISS, Pinecone).
- Look for benchmarks on retrieval performance degradation when using signed embeddings.
- See if the paper discusses practical deployment for large-scale astronomical catalogs (e.g., millions of embeddings).
