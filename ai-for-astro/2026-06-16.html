SciOrch: Learning to Orchestrate Expert LLMs for Solving Frontier Multimodal Scientific Reasoning Tasks

Jingru Guo , Xiangyuan Xue , Lian Zhang , Wanghan Xu , Siki Chen , Philip Torr , Wanli Ouyang , Lei Bai , Zhenfei Yin

arXiv PDF

Short Digest

This paper tackles the challenge of frontier scientific reasoning, where even the best LLMs fall short. It presents SciOrch, a framework that trains a lightweight 8B model to orchestrate calls to multiple commercial LLMs, decomposing questions and synthesizing answers. The orchestrator is trained using MCTS and GRPO to optimize the delegation strategy. For astronomy, this could enable an agent that combines specialized models for tasks like source classification, SED fitting, and literature review. A concrete workflow could be a multi-model agent that queries different LLMs for interpreting JWST spectra, cross-checking results, and producing a final analysis. A caveat is the API cost and latency of calling multiple commercial models, though the paper claims lower cost than typical multi-agent methods.

Reason

Directly addresses scientific reasoning with LLMs, using an orchestrator to combine multiple expert models. Highly relevant to automated scientific discovery and research agents for astronomy.

Full-Text Inspection Checklist

  • Look for the specific scientific domains tested (SGI-Reasoning, Scientists' First Exam) to assess overlap with astronomy.
  • Check the MCTS-based training details to see if the orchestrator can be adapted to domain-specific sub-tasks.
  • Examine the API cost analysis to evaluate feasibility for large-scale astronomy projects.
Abstract

Frontier scientific reasoning remains a major challenge for large language models (LLMs), where even the strongest commercial systems fall short of expert-level performance. A closer look at model behavior reveals substantial complementarity that single-model evaluation hides: different frontier models excel on different question types, and no single model captures the full picture. We present SciOrch, a framework that trains a lightweight 8B model to orchestrate frontier LLMs for scientific reasoning. The orchestrator decomposes each question, delegates sub-problems to selected commercial models through API calls, and synthesizes a final answer. Training such an orchestrator is fundamentally harder than conventional agentic RL: each action triggers an API call that is expensive in both dollar cost and latency, making standard online rollouts infeasible. We address this with MCTS-based approach, producing diverse orchestration trajectories, extracting per-node single-turn samples, and optimizing the orchestrator with GRPO-style training. On a 240-question test set spanning SGI-Reasoning and Scientists' First Exam, SciOrch reaches 56.66% average accuracy, outperforming the strongest single commercial model by 3.74% and the strongest multi-agent baseline by 3.33%. It also attains the best accuracy on both SGI and SFE with less than half the API cost of typical multi-agent methods.

SING: Synthetic Intention Graph for Scalable Active Tool Discovery in LLM Agents

Qiao Xiao , Haochen Shi , Yisen Gao , Wenbin Hu , Huihao Jing , Tianshi Zheng , Baixuan Xu , Ziheng Zhang , Weiqi Wang , Haoran Li , Jiaxin Bai , Yangqiu Song

arXiv PDF

Short Digest

This paper asks how LLM agents can dynamically discover and select the right tools from a large, evolving ecosystem (hundreds to thousands of APIs) rather than relying on a fixed, predefined inventory. It proposes SING, an intention-aware active tool discovery framework that builds an intention-tool graph linking user intentions, tool capabilities, and tool collaboration patterns, then retrieves tools according to the agent's evolving task state. For astronomy, this is directly applicable: an astronomy research agent could use SING to dynamically select the right data analysis tool (e.g., a photometric redshift code, a spectral fitting routine, a catalog cross-matching service) based on the current research question and intermediate results. A concrete workflow would be an agent that, when asked 'Find little red dots in this JWST field and fit their SEDs', uses SING to first retrieve a source detection tool, then a photometry tool, then an SED-fitting tool, all without hardcoding the pipeline. A key caveat is that SING requires a pre-built intention-tool graph, which would need to be constructed for astronomy-specific tools and APIs.

Reason

Directly addresses retrieval-augmented tool selection for LLM agents, which is highly relevant to building research agents for astronomy that can query databases, run codes, and access APIs.

Full-Text Inspection Checklist

  • Look for the graph construction method: how are intentions, tool capabilities, and collaboration patterns defined and linked?
  • Check whether the retrieval is truly dynamic (i.e., updates as the agent's state changes) or only at the start of a task.
  • Examine the evaluation on real-world tool-use benchmarks to see if the method scales to hundreds of tools without performance degradation.
Abstract

Large language model (LLM) agents increasingly rely on agent harnesses that manage context, tools, and multi-turn execution, making tools a central interface for acting in realistic digital environments. As harness-connected tool ecosystems expand to hundreds or thousands of APIs, services, and task-specific skills, exhaustive tool schema injection becomes costly and imposes a closed-world assumption that limits agents to a predefined static inventory. Retrieval-augmented tool selection offers a natural alternative, but existing one-shot retrieval methods often fail to align isolated tool descriptions with the agent's true task intention, especially in long-horizon tasks where required capabilities emerge through decomposition, observations, and newly induced subgoals. We propose SING, an intention-aware active tool discovery framework that builds an intention-tool graph linking user intentions, tool capabilities, and tool collaboration patterns, and dynamically retrieves tools according to evolving task states. Using a unified corpus of 7,471 tools, we evaluate SING on three real-world tool-use benchmarks. SING improves Global Recall@5 by up to 59.8% and downstream success rate by up to 28.9% over baselines, while reducing full-corpus tool-schema exposure by 99.8%, demonstrating that intention-aware graph structure enables more accurate and context-efficient tool discovery in large-scale agentic ecosystems.

VeriGraph: Towards Verifiable Data-Analytic Agents

Jiajie Jin , Zhao Yang , Wenle Liao , Yuyang Hu , Guanting Dong , Xiaoxi Li , Yutao Zhu , Zhicheng Dou

arXiv PDF

Short Digest

This paper asks how to make LLM-based data-analytic agents verifiable, so that their numerical conclusions and qualitative judgments can be audited and reproduced. It proposes VeriGraph, a framework that constructs an explicit heterogeneous evidence directed acyclic graph (DAG) during execution, connecting raw data, computed results, and natural-language claims. Three evidence-expansion primitives (computational, grounding, derivational) are introduced, and a graph-based policy optimization strategy with a composite reward supervises answer correctness, computational integrity, and derivational coherence. For astronomy, this is directly applicable: an astronomy research agent that queries catalogs, runs analysis code, and generates scientific claims could use VeriGraph to produce an auditable trail from raw JWST images to published conclusions. A concrete workflow would be an agent that, when asked 'What is the redshift distribution of little red dots in this field?', produces a DAG showing the exact SQL queries, photometric redshift code, and derived claims, enabling full reproducibility. A key caveat is that VeriGraph requires the agent to be built with the specific evidence-expansion primitives, which may require significant engineering for astronomy-specific tools.

Reason

Directly addresses verifiability and traceability of LLM-based data-analytic agents, which is crucial for reproducible scientific research in astronomy.

Full-Text Inspection Checklist

  • Look for the definition of the three evidence-expansion primitives: how are computational, grounding, and derivational expansions implemented for tabular and code-based data?
  • Check whether the Grounding Rate metric (87.61%) is evaluated on claims that are typical for scientific analysis (e.g., 'The mean redshift is 2.3') or only on simple factual claims.
  • Examine the graph-based policy optimization: does the composite reward require ground-truth annotations for computational integrity and derivational coherence, or can it be self-supervised?
Abstract

LLM-based agents have demonstrated strong capabilities in data-intensive analytical tasks, yet their outputs are rarely verifiable: a reliance on linear text trajectories makes their reasoning difficult to audit. In particular, deterministic computations over raw data and semantic deductions over natural-language claims are often entangled in an unstructured stream, leaving numerical conclusions hard to reproduce and qualitative judgments hard to inspect. To address this, we propose VeriGraph, a traceable neuro-symbolic reasoning framework that enables agents to construct an explicit heterogeneous evidence directed acyclic graph (DAG) during execution. VeriGraph introduces three evidence-expansion primitives, namely computational, grounding, and derivational expansion, to connect raw data, interpreter variables, computed results, and natural-language claims in a unified graph. Under this formulation, structural traceability is reduced to graph reachability from raw data sources to terminal claims, while semantic support is measured by claim-level evidence evaluation. To improve graph construction, we further design a graph-based policy optimization strategy with a composite reward that jointly supervises answer correctness, computational integrity, and derivational coherence. Experiments on four benchmarks show that VeriGraph-8B achieves the highest overall score among all baselines. More importantly, VeriGraph produces auditable evidence graphs with substantially stronger claim grounding, achieving a 87.61\% Grounding Rate under our claim-level evidence support evaluation. These results suggest that explicit evidence-graph construction is a promising path toward verifiable data-analytic agents. Our code is available at this https URL .

Remember, Don't Re-read: Stateful ReAct Agents for Token-Efficient Autonomous Experimentation

Faramarz Jabbarvaziri

arXiv PDF

Short Digest

This paper reformulates the autoresearch pattern as a stateful ReAct agent using LangGraph, reducing token consumption by 52-90% compared to stateless approaches. The agent carries experimental history across iterations via a persistent state, avoiding re-reading full history. For astronomy, this could enable efficient automated hyperparameter tuning or code optimization for data analysis pipelines. The method is demonstrated on hyperparameter tuning and code performance optimization. The main caveat is that the benchmarks are not astronomy-specific, but the architecture is general.

Reason

Directly addresses token-efficient autonomous experimentation with LLM agents, which is highly relevant for automated scientific discovery workflows.

Full-Text Inspection Checklist

  • Look for details on the state management and tool-calling interface for reproducibility.
  • Check if the agent can handle long experimental histories without performance degradation.
Abstract

The autoresearch pattern enables autonomous experimentation by having a large language model (LLM) iteratively modify code to optimize a target metric. Its stateless design, however, reconstructs experimental context from scratch at every iteration, incurring $O(n)$ token cost per iteration and $O(n^{2})$ total. This work reformulates the pattern as a stateful ReAct agent using LangGraph, where typed persistent state carries experimental history across iterations via a tool-calling interface. Two benchmarks are evaluated: hyperparameter tuning (15 iterations, small per-iteration observations) and code performance optimization (40 iterations, large per-iteration observations containing full source code and benchmark results). On hyperparameter tuning, the stateful agent consumes 90\% fewer tokens (2{,}492 vs.\ 24{,}465). On code optimization, the stateful agent consumes 52\% fewer tokens (627K vs.\ 1{,}275K) while achieving comparable optimization quality on both tasks. The token reduction is structural: the stateless agent re-reads the full history at $O(n)$ cost per iteration, while the stateful agent operates within a fixed-size conversation window at $O(1)$ cost. This paper describes the architecture in sufficient detail for practitioners to implement a stateful autoresearch agent for their own workflows.

Retrievable Gradients: Continual Post-Training Without Cumulative Weight Drift

Weihang Su , Jiacheng Kang , Jingyan Xu , Qingyao Ai , Jianming Long , Hanwen Zhang , Bangde Du , Xinyuan Cao , Min Zhang , Yiqun Liu

arXiv PDF

Short Digest

This paper addresses the problem of continual post-training for language models, where updating parameters with new knowledge can cause catastrophic forgetting. The authors propose ReGrad, which treats gradients as retrievable units of knowledge, pre-computing document-specific gradients offline and retrieving only query-relevant gradients at inference time for temporary weight adaptation. This approach combines the benefits of retrieval-augmented generation with parametric knowledge integration, avoiding cumulative weight drift. For astronomy, this could enable models to incorporate new observational data or literature without retraining, which is valuable for large surveys like JWST, Roman, or Rubin. A concrete workflow could involve using ReGrad to update a model with new spectral or imaging catalogs, allowing it to answer queries about new objects without full retraining. The method requires pre-computing gradients for new documents, which may be computationally intensive, and the meta-learning objective may need tuning for astronomical data.

Reason

This paper proposes a method for continual post-training without weight drift, which could be highly relevant for updating astronomical models with new survey data without catastrophic forgetting.

Full-Text Inspection Checklist

  • Check whether the paper provides experiments on domain-specific datasets that resemble astronomical data (e.g., scientific literature or structured knowledge).
  • Look for details on the computational cost of pre-computing gradients and the scalability to large document collections.
  • Examine the meta-learning objective and whether it can be adapted to multimodal data (images, spectra, catalogs).
Abstract

Continual post-training enables models to absorb emerging knowledge after deployment, but repeatedly updating shared parameters can accumulate weight drift, potentially causing catastrophic forgetting and degrading general capabilities. Retrieval-augmented generation avoids such parameter drift, yet often lacks the depth of parametric knowledge integration. In this paper, we propose ReGrad (Retrievable Gradients), a new paradigm that treats gradients as retrievable units of knowledge. ReGrad pre-computes document-specific gradients offline, stores them in an indexed Gradient Bank, and retrieves only query-relevant gradients at inference time for temporary weight adaptation. However, raw language-modeling gradients are optimized for token-level document reconstruction rather than for query-driven knowledge use. We therefore introduce a bi-level meta-learning objective that reshapes document-derived gradients into generalizable adaptation signals for downstream tasks. Experiments across general and domain-specific settings show that \textsc{ReGrad} outperforms CPT and RAG baselines, enabling scalable and reversible parametric knowledge injection without accumulating weight drift.

Intelligent Multimodal Retrieval and Reasoning for Geospatial Knowledge Discovery on the I-GUIDE Platform

Yunfan Kang , Erick Li , Furqan Baig , Wei Hu , Alexander Michels , Anand Padmanabhan , Shaowen Wang

arXiv PDF

Short Digest

This paper presents I-GUIDE Smart Search, a production multimodal retrieval-augmented generation (RAG) system for geospatial knowledge discovery. It combines OpenSearch indexes, a Neo4j knowledge graph, and an iterative RAG pipeline with memory-aware query augmentation, reasoning, and hallucination checking. The system handles heterogeneous artifacts: datasets, maps, notebooks, software, and publications. For astronomy, this is directly relevant as a template for building a RAG system that searches across astronomical catalogs, papers, code repositories, and provenance links. The paper reports deployment lessons on spatial metadata quality, graph provenance, retrieval routing, and latency-cost tradeoffs that transfer to astronomical cyberinfrastructure. A limitation is the 25-second p50 latency due to 20-50 LLM calls per query, which may need optimization for interactive astronomy use.

Reason

Multimodal RAG system for geospatial knowledge discovery; directly relevant to astronomical RAG systems for literature, data, and provenance search.

Full-Text Inspection Checklist

  • Look for the system architecture diagram showing how OpenSearch, Neo4j, and the RAG pipeline are integrated
  • Check the evaluation benchmark: 170 human-filtered queries and 10 intent-specific probe sets
  • Examine the latency breakdown: 4.4 req/s with p50 ~25 seconds and 20-50 LLM calls per query
  • Look for the 'transferable deployment lessons' section on spatial metadata quality and retrieval routing
Abstract

Geospatial knowledge discovery increasingly requires search across heterogeneous artifacts: datasets, maps, notebooks, software, publications, and the provenance links among them. Conventional geoportals support metadata and spatial filtering, but they rarely provide semantic retrieval, graph-aware provenance traversal, and conversational synthesis in one integrated system. This paper presents I-GUIDE Smart Search, a production multimodal geospatial retrieval-augmented generation (RAG) system embedded in the I-GUIDE Platform, and reports on its design, deployment, and evaluation. The system combines production-maintained OpenSearch keyword, vector, and spatial indexes with a Neo4j knowledge graph and an iterative RAG pipeline for memory-aware query augmentation, reasoning, retrieval-method routing, relevance grading, grounded generation, hallucination and relevance checking. In a single-A100 RAG deployment, I-GUIDE Smart Search supports interactive use up to about 100 concurrent simulated users, reaching 4.4 requests per second with p50 latency near 25 seconds despite 20-50 LLM calls per query. For answer quality, we evaluate a four-category benchmark of 170 unique human-filtered user-facing queries, together with ten intent-specific probe sets generated from the deployed indexes and graph. Smart Search improves retrieved evidence coverage and judged answer quality over non-retrieval and naive-RAG baselines, with the clearest gains on exact-identifier, spatially constrained, simple-recommendation, and domain-specific factual queries requiring current indexed evidence. We distill transferable deployment lessons for spatial RAG systems, covering spatial metadata quality, graph provenance, retrieval routing, interface contracts, refusal-aware evaluation, latency-cost tradeoffs, and the role of the user interface in deployed geospatial cyberinfrastructure.

RepNet: Tackling spectral bias in deep neural networks via parameter reparameterization

Yong Wang , Tao Zhou , Xuhui Meng

arXiv PDF

Short Digest

This paper tackles the problem of spectral bias in deep neural networks, where they fail to capture high-frequency or oscillatory patterns. It proposes RepNet, a reparameterization of the first hidden layer's weights and biases to control initial slope scales and partition point distributions, enabling adaptive frequency scaling during training. For astronomy, this is directly relevant because many astrophysical signals (e.g., spectral lines, light curves, SEDs) contain high-frequency or multiscale features that standard neural networks struggle to learn. A concrete workflow could be using RepNet within a physics-informed neural network (PINN) to fit galaxy SEDs or spectral line profiles from JWST data. A key caveat is that the method is demonstrated on synthetic and PDE problems, not yet on real astronomical data, so performance on noisy, irregularly sampled observations needs validation.

Reason

Addresses spectral bias in neural networks for high-frequency and multiscale problems, directly relevant to astronomical data analysis (e.g., spectral fitting, SED fitting, oscillatory signals).

Full-Text Inspection Checklist

  • Check if the method is tested on noisy or irregularly sampled data, as astronomical observations often are
  • Look for quantitative comparisons on multiscale function approximation—how much improvement over vanilla DNNs?
  • Assess whether the reparameterization is compatible with common astronomical data formats and loss functions
Abstract

Deep neural networks (DNNs) have achieved remarkable success in scientific computing, yet they often suffer from spectral bias in capturing oscillatory and multiscale behaviors. In this study, we investigate this limitation by examining the failure of shallow ReLU neural networks in fitting high-frequency functions. This observation identifies two important factors in resolving rapid oscillations: the initial slope scale and the distribution of partition points induced by the networks. Motivated by this analysis, we propose RepNet, a reparameterized DNN model for ReLU and tanh networks designed for high-frequency and multiscale problems. The key idea is to reparameterize the weights and biases in the first hidden layer, which enables effective control of the initial slope scale and provides an appropriate distribution of the initial partition points. Furthermore, treating the reparameterized weights and biases as trainable parameters allows the DNN to achieve adaptive frequency scaling during training. In addition, we derive quantitative estimates for the output and slope magnitudes of the reparameterized DNN to guide the initialization of the proposed method. Numerical experiments, including multiscale one- and four-dimensional function approximation, forward and inverse PDE problems in combination with physics-informed neural networks (PINNs), and operator learning, demonstrate that RepNet improves the predicted accuracy of vanilla DNNs in capturing highly oscillatory features with slightly additional computational cost. These results indicate that RepNet provides an effective and flexible approach for overcoming spectral bias and applying DNNs to multiscale problems.

LOCUS: Local Visual Cue Search for Enhancing Fine-Grained Perception in Multimodal Large Language Models

Zhou Tao , Fang Zhang , Zewen Ding , Shida Wang , Xiaokun Sun , YongXiang Hua , Haoyu Cao , Linli Xu

arXiv PDF

Short Digest

This paper asks why multimodal large language models (MLLMs) still fail on fine-grained visual tasks even with high-resolution inputs. It identifies 'visual context rot' where decisive local evidence exists but is not reliably selected by the model. The authors propose LOCUS, a training framework that teaches MLLMs to internalize local evidence search by providing a local crop as a visual cue during training and optimizing the model to recover its spatial location in the full image using an IoU-based reward. For astronomy, this could directly improve MLLM-based analysis of JWST images where small, high-redshift galaxies or AGN require fine-grained localization and classification. A concrete workflow would be using LOCUS-trained MLLMs to answer questions like 'Is there a compact red source in this JWST NIRCam image?' or to locate little red dots. A key caveat is that LOCUS requires training with paired crop-full-image data, which may need custom dataset construction for astronomical images.

Reason

Directly addresses fine-grained visual perception in MLLMs, which is critical for analyzing high-resolution JWST images and detecting small, faint sources like little red dots.

Full-Text Inspection Checklist

  • Look for the IoU-based reward formulation and whether it can be adapted to bounding-box or segmentation tasks common in astronomy.
  • Check whether the method is evaluated on any natural images with small objects (e.g., birds, insects) that mimic the scale of high-redshift sources.
  • Examine the attention analysis figures to see if the model truly focuses on task-relevant regions after LOCUS training.
Abstract

Multimodal Large Language Models (MLLMs) remain unreliable on fine-grained visual perception, even when high-resolution inputs preserve the necessary local details. We identify this limitation as visual context rot: decisive evidence may exist in the full image, yet fail to be reliably selected and used amid redundant visual context. We propose LOCUS (LOcal visual CUe Search), a training framework that teaches MLLMs to internalize local evidence search through a verifiable proxy task. During training, LOCUS provides a local crop as a visual cue and optimizes the model to recover its spatial support in the full image using an IoU-based reward. The visual cue is used only during training, leaving the standard image-question inference interface unchanged. Experiments across fine-grained perception, hallucination, general understanding, and reasoning benchmarks show that LOCUS improves localization-sensitive visual understanding while preserving broad capabilities. Attention analyses further indicate stronger focus on task-relevant evidence regions, suggesting that training-time visual cue search provides an effective route to internalized fine-grained evidence selection.
