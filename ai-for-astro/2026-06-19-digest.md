## 1. Language-Instructed Vision Embeddings for Controllable and Generalizable Perception

- arXiv ID: `2606.19584`
- Authors: Chengzhi Mao , Xudong Lin , Wen-Sheng Chu
- Score: 8
- Link: https://arxiv.org/abs/2606.19584
- PDF: https://arxiv.org/pdf/2606.19584
- Subjects: Computer Vision and Pattern Recognition (cs.CV)
- Reason: Proposes a method to use language to guide vision embeddings, directly applicable to multimodal models for astronomy (e.g., image + text queries).

Short digest:
This paper proposes LIVE, a method that uses language instructions to dynamically guide a vision encoder at inference time. Instead of static feature extraction, the encoder focuses on contextually relevant aspects based on a text prompt. This reduces hallucinations and improves generalization to unseen tasks. For astronomy, this could enable querying JWST images with natural language (e.g., 'find little red dots') without retraining. It could also be used for multimodal classification or retrieval across images and catalogs. The method is demonstrated on visual question answering and could transfer to astronomical image analysis.

Full-text inspection checklist:
- Check if the method can handle astronomical images with different filters or bands.
- Look for details on how the language guidance is integrated into the vision encoder.
- See if the approach is demonstrated on tasks beyond the benchmarks, e.g., fine-grained classification.

- Score: 8
- Link: https://arxiv.org/abs/2606.19700

- Subjects: Computation and Language (cs.CL)
- Reason: Paper directly applies a small language model (SLM) to extract structured information from planetary science literature, which is a clear analog to astronomy literature mining.

Short digest:
This paper addresses the problem of extracting structured data from Mars science literature to support terraforming research. The authors build TerraMARS, a pipeline that uses a fine-tuned Google Gemma 3 1B model with QLoRA to answer questions and extract JSON-formatted information from papers. This is directly relevant to astronomy because the same approach could be used to extract physical parameters (redshifts, metallicities, fluxes) from JWST papers or survey catalogs. An astronomer could imagine using this pipeline to automatically build a database of high-redshift galaxy properties from the literature. A caveat is that the paper reports 'promising' results but acknowledges the need for improved extraction accuracy and factual consistency, and the model is small (1B parameters) which may limit performance on complex astronomical terminology.

Full-text inspection checklist:
- Check the reported extraction accuracy (F1 scores) for entity and relationship extraction on Mars-specific data
- Look for details on the QLoRA fine-tuning procedure and whether the model can be adapted to astronomy-specific ontologies
- Examine the chunking and retrieval strategy to see if it handles long, technical documents with equations and tables

- arXiv ID: `2606.20047`
- Authors: Manu Ghulyani , Arunabh Singh , Karan Bharadwaj , Ankit Nath , Suranjan Goswami
- Score: 8
- Link: https://arxiv.org/abs/2606.20047
- PDF: https://arxiv.org/pdf/2606.20047
- Subjects: Information Retrieval (cs.IR)
- Reason: Directly addresses context selection for LLM agents, a core challenge for building research agents that can handle long astronomy workflows and literature reviews.

Short digest:
This paper tackles the problem of context overflow in LLM agents, where recency truncation discards important early information. It proposes a submodular context selection method that treats memory, conversation turns, and tool outputs as a single pool, selecting the most relevant pieces at prompt assembly time. For astronomy, this could enable a research agent that maintains long-term memory of a galaxy's properties across many analysis steps. One could imagine using it to build an agent that iteratively fits SEDs, checks photometric redshifts, and queries literature without forgetting earlier results. A key caveat is that the paper does not provide experimental results or comparisons, only a problem description and proposed approach.

Full-text inspection checklist:
- Check for any experimental validation or ablation studies on the proposed submodular selection method.
- Look for details on how the method handles different types of context (memory, tool outputs, conversation turns).
- Assess whether the method is model-agnostic or tied to a specific LLM.

## 6. When Does Streaming Tool Use Help? Characterizing Tool-Intent Stabilization in Streaming Retrieval-Augmented Generation

- arXiv ID: `2606.20113`
- Authors: Elroy Galbraith
- Score: 8
- Link: https://arxiv.org/abs/2606.20113
- PDF: https://arxiv.org/pdf/2606.20113
- Subjects: Computation and Language (cs.CL) ; Information Retrieval (cs.IR)
- Reason: Directly addresses streaming retrieval-augmented generation (RAG) for tool use, highly relevant for building LLM agents that query astronomical databases in real time.

Short digest:
This paper asks when streaming RAG (issuing tool queries before user input is complete) actually helps reduce latency. It introduces the concept of tool-intent stabilization and derives a model-agnostic bound on latency hiding. The main result is that 73.9% of queries admit substantial latency hiding at a realistic operating point, with early stabilization on favorable slices. This matters for astronomy because LLM agents that query databases (e.g., SIMBAD, NED, ADS) in real time could benefit from reduced perceived latency. A concrete workflow could be an agent that suggests astronomical sources while the user types a query. A caveat is that the study uses the CRAG benchmark (general knowledge), not astronomical databases, so the stabilization distribution may differ.

Full-text inspection checklist:
- Check whether the stabilization analysis is performed on question types that resemble astronomical queries.
- Look for the specific tool latency and input cadence assumptions and whether they match typical astronomical database response times.

However, the methodology for aligning heterogeneous data modalities could transfer to astronomical multi-wavelength analysis.
