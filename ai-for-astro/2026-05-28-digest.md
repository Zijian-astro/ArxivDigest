## 1. GenSBI: Generative Methods for Simulation-Based Inference in JAX

- arXiv ID: `2605.27499`
- Authors: Aurelio Amerio
- Score: 9
- Link: https://arxiv.org/abs/2605.27499
- PDF: https://arxiv.org/pdf/2605.27499
- Subjects: Machine Learning (cs.LG) ; Cosmology and Nongalactic Astrophysics (astro-ph.CO); Instrumentation and Methods for Astrophysics (astro-ph.IM); Computational Physics (physics.comp-ph); Machine Learning (stat.ML)
- Reason: Directly provides a JAX-based library for simulation-based inference using flow matching and diffusion models, which is highly relevant for SED fitting, spectral fitting, and parameter estimation in astronomy.

Short digest:
This paper presents GenSBI, an open-source library in JAX for simulation-based inference (SBI) using flow matching, score matching, and denoising diffusion models. SBI is a powerful framework for estimating parameters from complex simulations where the likelihood is intractable, which is common in astronomy (e.g., galaxy formation models, SED fitting). The library offers transformer-based architectures and a unified interface for posterior, likelihood, and joint density estimation, with built-in calibration diagnostics. This is directly relevant to astronomy because it could be used to infer physical parameters of high-redshift galaxies from JWST data by training on simulated spectra or images. A concrete workflow would be using GenSBI to train a neural posterior estimator on simulated galaxy SEDs, then applying it to real JWST/NIRSpec observations to infer stellar mass, age, metallicity, and dust. A key caveat is that the library is JAX-based, which may require migrating from PyTorch workflows, and the benchmarks are on simple SBI tasks (SBIBM), not astronomical simulations. Prerequisites include familiarity with SBI concepts and JAX.

Full-text inspection checklist:
- Check if the library supports custom embedding networks for domain-specific features (e.g., spectral line indices or photometric bands)
- Look for documentation on integrating with astronomical simulation codes (e.g., FSPS, CIGALE, or BEAGLE)
- Examine the posterior calibration diagnostics (SBC, TARP, LC2ST) for applicability to multi-modal or degenerate posteriors common in SED fitting

## 3. SkillGrad: Optimizing Agent Skills Like Gradient Descent

- arXiv ID: `2605.27760`
- Authors: Hanyu Wang , Yifan Lan , Bochuan Cao , Lu Lin , Jinghui Chen
- Score: 8
- Link: https://arxiv.org/abs/2605.27760
- PDF: https://arxiv.org/pdf/2605.27760
- Subjects: Artificial Intelligence (cs.AI)
- Reason: Directly addresses optimizing LLM agent skills via a gradient-descent-inspired framework, which is highly relevant to automated scientific discovery and research agents for astronomy.

Short digest:
This paper tackles the problem that agent skills (reusable procedural knowledge for LLM agents) are often unreliable, incomplete, or outdated when downloaded or self-generated. The authors propose SkillGrad, a framework that treats the skill package as a structured parameter to optimize using a gradient-descent-like process: task executions provide trajectory-level loss, automatic diagnoses provide text-based gradients, and a momentum agent accumulates recurring patterns to stabilize optimization. For astronomy, this could enable automated refinement of data-analysis workflows, such as tuning a multi-step pipeline for JWST source classification or SED fitting. A concrete workflow would be using SkillGrad to iteratively improve an agent that retrieves and processes astronomical catalogs, reducing manual debugging. However, the method is evaluated on spreadsheet and table QA tasks, so its transfer to astronomy-specific tools (e.g., astropy, photutils, or JWST pipeline steps) would require adapting the skill representation and diagnosis feedback to domain-specific APIs.

Full-text inspection checklist:
- Check whether the skill package format (structured files) can represent astronomy workflows like multi-step data reduction or model-fitting scripts.
- Look for details on how the text-based gradients (diagnoses) are generated and whether they could incorporate domain-specific error messages (e.g., from JWST pipeline failures).
- Examine the momentum memory overlay mechanism to see if it can capture recurring issues in astronomical data processing (e.g., persistent calibration artifacts).

## 4. ResearchLoop: An Evidence-Gated Control Plane for AI-Assisted Research

- arXiv ID: `2605.28282`
- Authors: Yihan Xia , Taotao Wang
- Score: 8
- Link: https://arxiv.org/abs/2605.28282
- PDF: https://arxiv.org/pdf/2605.28282
- Subjects: Artificial Intelligence (cs.AI)
- Reason: Directly addresses AI-assisted research with an evidence-gated control plane, highly relevant for automated scientific discovery and reproducible workflows in astronomy.

Short digest:
This paper aims to solve the problem of unverifiable claims in AI-assisted research by introducing an evidence-gated control plane. The core idea is a structured protocol that treats research questions, task contracts, evidence objects, and claim ledgers as durable project state, ensuring every claim is backed by evidence before it can be included in a paper. This matters for astronomy because it provides a framework for building trustworthy AI agents that can perform literature review, data analysis, and code generation while maintaining auditability and reproducibility. An astronomer could imagine using ResearchLoop to manage a project where an LLM agent searches JWST data for little red dots, fits SEDs, and writes a paper, with every claim automatically linked to the evidence. A key limitation is that the paper is a technical report of a protocol, not a deployed system, and its effectiveness depends on the quality of the underlying AI models and the user's ability to define task contracts.

Full-text inspection checklist:
- Look for the protocol specification details: how are 'evidence objects' defined and verified? Can they include astronomical data products like spectra or cutouts?
- Check the claim-admission algorithm: does it require human-in-the-loop verification, or is it fully automated? How does it handle uncertainty in evidence?
- See the experimental record (V0-V9): are there any case studies involving scientific data analysis (e.g., from SciCode) that demonstrate the workflow on a realistic astronomy problem?
- Examine the 'insight-compounding mechanism': does the system allow building on previous results, and how does it prevent error propagation?

- Score: 8
- Link: https://arxiv.org/abs/2605.28371
- PDF: https://arxiv.org/pdf/2605.28371
- Subjects: Artificial Intelligence (cs.AI) ; Machine Learning (cs.LG); Software Engineering (cs.SE)
- Reason: Directly addresses agentic reproduction of scientific methods, which is highly relevant for automated scientific discovery and reproducible research in astronomy.

Short digest:
This paper tackles the challenge of reproducing under-specified machine learning methods from published papers. It introduces an agentic framework that translates papers into a shared benchmark framework via a slot-binding interface, mapping equations and protocols into structured components. The approach ensures consistent and comparable benchmarking across papers. For astronomy, this could automate the reproduction of methods for source classification, SED fitting, or spectral analysis from the literature. The framework explicitly records unresolved assumptions, which is crucial for trust in automated scientific workflows. A key caveat is that the method is demonstrated on industrial PHM papers, not astronomy, so adaptation to astronomical methods and datasets would be needed.

Full-text inspection checklist:
- Check if the slot-binding interface can be extended to astronomical tasks like photometric redshift estimation or galaxy morphology classification.
- Look for evaluation on papers with incomplete reporting of preprocessing or evaluation protocols, which is common in astronomy.
