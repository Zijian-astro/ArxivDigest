## 1. Towards Self-Evolving Agentic Literature Retrieval

- arXiv ID: `2605.14306`
- Authors: Yuwen Du , Tian Jin , Jing Kang , Xianghe Pang , Jingyi Chai , Tingjia Miao , Fenyi Liu , WenHao Wang , Sikai Yao , Yuzhi Zhang , Siheng Chen
- Score: 9
- Link: https://arxiv.org/abs/2605.14306
- PDF: https://arxiv.org/pdf/2605.14306
- Subjects: Information Retrieval (cs.IR)
- Reason: Directly addresses automated literature retrieval for scientific research, with a self-evolving agentic system that could be applied to astronomy literature review and discovery.

Short digest:
This paper aims to solve the problem of literature retrieval for scientific research, where traditional keyword search fails to capture complex intents and LLMs hallucinate. It introduces PaSaMaster, a self-evolving agentic system that iteratively refines search intents, retrieves papers, and ranks them by relevance with evidence-grounded recommendations. The system uses a frontier LLM only for intent understanding, while large-scale retrieval is done with lightweight models, achieving zero source hallucination. For astronomy, this could be used to automatically find papers relevant to specific JWST observations, high-redshift galaxy studies, or AGN classification, by iteratively refining search queries based on initial results. The system outperforms GPT-5.2 at 1% of the cost, making it practical for routine use. However, the benchmark covers 38 scientific disciplines but does not specifically test on astronomy literature.

Full-text inspection checklist:
- Look for the evaluation on astronomy-specific queries or papers to assess domain coverage.
- Check the ranking algorithm to see if it can handle domain-specific relevance criteria (e.g., instrument, redshift range, methodology).
- See if the system can be customized with astronomy-specific corpora (e.g., NASA ADS, arXiv astro-ph).
- Examine the evidence-grounded recommendations to ensure they provide useful citations and reasoning for astronomy papers.

## 2. GEAR: Genetic AutoResearch for Agentic Code Evolution

- arXiv ID: `2605.13874`
- Authors: Ahmadreza Jeddi , Minh Ngoc Le , Hakki C. Karaimer , Konstantinos G. Derpanis , Babak Taati
- Score: 8
- Link: https://arxiv.org/abs/2605.13874
- PDF: https://arxiv.org/pdf/2605.13874
- Subjects: Neural and Evolutionary Computing (cs.NE) ; Artificial Intelligence (cs.AI)
- Reason: This paper presents an autonomous research agent that uses population-based search over multiple research states, which is directly relevant to automated scientific discovery for astronomy.

Short digest:
This paper addresses the problem that autonomous research agents often use a narrow single-path search strategy that discards useful partial ideas. The authors propose GEAR, which maintains a population of candidate solutions and uses mutation and crossover to explore new ideas, similar to genetic algorithms. For astronomy, this could be used to automatically explore different analysis pipelines for JWST data, such as testing multiple SED fitting models or source classification methods. A concrete workflow could be using GEAR to autonomously search over hyperparameters and model architectures for photometric redshift estimation or anomaly detection in survey data. A key caveat is that GEAR is demonstrated on machine learning experiment optimization, not directly on astronomical data, so adaptation would be needed.

Full-text inspection checklist:
- Check if the method is demonstrated on any scientific or astronomical dataset.
- Look for details on how the search space is defined and how candidate solutions are represented.
- Check if the paper discusses transferability to other domains like astronomy.

## 3. Collider-Bench: Benchmarking AI Agents with Particle Physics Analysis Reproduction

- arXiv ID: `2605.13950`
- Authors: Darius A. Faroughy , Sofia Palacios Schweitzer , Ian Pang , Siddharth Mishra-Sharma , David Shih
- Score: 8
- Link: https://arxiv.org/abs/2605.13950
- PDF: https://arxiv.org/pdf/2605.13950
- Subjects: Machine Learning (cs.LG) ; Artificial Intelligence (cs.AI); High Energy Physics - Experiment (hep-ex); High Energy Physics - Phenomenology (hep-ph)
- Reason: This benchmark evaluates LLM agents on reproducing particle physics analyses, directly relevant to automated scientific discovery and research agents for astronomy.

Short digest:
This paper introduces Collider-Bench, a benchmark for evaluating whether LLM agents can reproduce experimental analyses from the Large Hadron Collider using only public papers and open scientific software. Each task requires the agent to turn a published analysis into an executable simulation-and-selection pipeline and submit predicted collision event yields. Agents must use physical reasoning, domain knowledge, and trial-and-error to fill gaps in the public toolchain and published papers. This is directly relevant to astronomy because the same approach could be applied to reproducing JWST or HST data analysis pipelines from papers. For example, an agent could be tasked with reproducing a high-redshift galaxy SED fitting analysis from a published paper. The benchmark provides a template for evaluating research agents on real scientific workflows. Limitations include the domain-specific nature of particle physics and the need for domain adaptation to astronomy.

Full-text inspection checklist:
- Check if the benchmark framework is extensible to astronomy analyses (e.g., JWST data reduction, SED fitting).
- Look for the evaluation metrics and whether they could be adapted to astronomical histogram comparisons (e.g., flux distributions).
- Examine the LLM judge for qualitative failure modes and whether it could detect hallucinations in astronomical reasoning.

## 4. Physics-R1: An Audited Olympiad Corpus and Recipe for Visual Physics Reasoning

- arXiv ID: `2605.14040`
- Authors: Shan Yang
- Score: 8
- Link: https://arxiv.org/abs/2605.14040
- PDF: https://arxiv.org/pdf/2605.14040
- Subjects: Computation and Language (cs.CL)
- Reason: Directly addresses multimodal physics reasoning with a rigorous evaluation pipeline, highly relevant for automated scientific discovery in astronomy.

Short digest:
This paper audits multimodal physics evaluation pipelines and documents train-eval contamination, translation drift, and MCQ saturation. It releases a cleaned corpus, a held-out olympiad evaluation set, and a reference recipe (Physics-R1) that lifts performance on open-ended physics reasoning. The recipe uses reinforcement learning (GSPO+DAPO) cold-started from a vision-language model. For astronomy, this is directly relevant because it provides a methodology for building and evaluating AI systems that reason about physics from images and text. The rigorous auditing approach could be applied to astronomical benchmarks. A key limitation is that the physics problems are olympiad-style, not astronomical, and the transfer to astronomical reasoning tasks is not demonstrated.

Full-text inspection checklist:
- Look for the auditing methodology to apply to astronomical benchmarks
- Check if the Physics-R1 recipe could be adapted to astronomical visual reasoning tasks
- Examine the evaluation metrics for open-ended reasoning that could be used for astronomical source classification or interpretation

## 6. SciPaths: Forecasting Pathways to Scientific Discovery

- arXiv ID: `2605.14600`
- Authors: Eric Chamoun , Yizhou Chi , Yulong Chen , Rui Cao , Zifeng Ding , Michalis Korakakis , Andreas Vlachos
- Score: 8
- Link: https://arxiv.org/abs/2605.14600
- PDF: https://arxiv.org/pdf/2605.14600
- Subjects: Computation and Language (cs.CL)
- Reason: Directly addresses scientific discovery pathway forecasting, which is core to automated scientific discovery and research agents.

Short digest:
This paper introduces discovery pathway forecasting: given a target scientific contribution, identify the enabling contributions and ground them in prior work. It presents SciPaths, a benchmark of 262 expert-annotated pathways from ML/NLP papers. The best model achieves only 0.189 F1, showing this is a hard problem. For astronomy, this could help map the dependencies needed to achieve a breakthrough (e.g., detecting biosignatures with JWST). A concrete workflow: using an LLM agent to propose a pathway for a new high-redshift galaxy analysis method. Caveat: the benchmark is limited to ML/NLP; astronomy-specific pathways would need new annotations.

Full-text inspection checklist:
- Look for the annotation guidelines and whether they can be adapted to astronomy.
- Check the evaluation metrics (F1 under strict semantic matching) and whether they capture partial credit.
- Examine the types of enabling contributions (method, data, theory) and their distribution.

## 7. Case-Based Calibration of Adaptive Reasoning and Execution for LLM Tool Use

- arXiv ID: `2605.15041`
- Authors: Renning Pang , Tian Lan , Leyuan Liu , Piao Tong , Sheng Cao , Xiaosong Zhang
- Score: 8
- Link: https://arxiv.org/abs/2605.15041
- PDF: https://arxiv.org/pdf/2605.15041
- Subjects: Artificial Intelligence (cs.AI) ; Computation and Language (cs.CL)
- Reason: Directly addresses LLM tool use and execution reliability, which is central to building LLM agents for scientific workflows. The case-based calibration approach could transfer to astronomical data analysis pipelines.

Short digest:
This paper tackles the problem of making LLMs more reliable when they call external tools or functions, a key capability for autonomous scientific agents. The authors propose CAST, a framework that learns from past tool-use trajectories to decide when to reason deeply and when to execute quickly, without needing to retrain the model. Instead of copying past examples, CAST extracts complexity and failure signals from historical runs to guide the model's reasoning strategy. For astronomy, this could mean building an agent that reliably queries databases, runs SED-fitting code, or calls JWST pipeline tools without making structural errors. A concrete workflow would be an agent that retrieves spectra from MAST, runs fitting, and returns results, where CAST could reduce errors from malformed API calls or missing parameters. The main caveat is that the method is evaluated on general tool-use benchmarks (BFCLv2, ToolBench), not on astronomy-specific tools, so transfer is plausible but unproven.

Full-text inspection checklist:
- Check whether the case library can be seeded with astronomy-specific tool trajectories or requires generic data.
- Look for the definition of 'structural errors' and whether they map to common mistakes in astronomical tool use (e.g., wrong column names, missing filters).
- Examine the reward design: is it task-agnostic or would it need to be redefined for astronomy workflows?
