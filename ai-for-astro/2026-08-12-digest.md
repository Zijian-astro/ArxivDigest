## 1. LLM Agents Factory: Retrieval of Domain-Specific LLM Agents

- arXiv ID: `2608.09934`
- Authors: Vitalii Belov , Artyom Sosedka , Andrey Sakhovskiy , Elizaveta Kovtun , Artyom Boyarskikh , Semen Budennyy
- Score: 7
- Link: https://arxiv.org/abs/2608.09934
- PDF: https://arxiv.org/pdf/2608.09934
- Subjects: Computation and Language (cs.CL) ; Artificial Intelligence (cs.AI)
- Reason: The paper proposes a retrieval-based framework for constructing domain-specific LLM agents, which could be adapted for astronomical research agents. It emphasizes cost-efficiency and controllability, relevant for building specialized agents for JWST data analysis.

Short digest:
The paper addresses the high computational cost and instability of designing LLM agents on-the-fly for each request. It introduces LLM Agents Factory, a retrieval-based system with over 20K pre-defined agent profiles, which can either retrieve an agent via semantic search or distill into a compact model for direct generation. This could matter for astronomy by enabling efficient, specialized agents for tasks like source classification or SED fitting without heavy compute. I could imagine using it to build a repository of agents for different JWST analysis workflows, such as one for photometric redshift estimation or another for spectral fitting. However, the paper tests on general NLP benchmarks (MMLU, BIG-bench), so I should check if the agent profiles are domain-agnostic or if they can be customized for astronomy-specific tasks.

Full-text inspection checklist:
- Check if the agent profiles are domain-specific or generic, and whether they can be customized for astronomy tasks.
- Look for details on how the retrieval base is constructed and whether it includes scientific domains.
- Examine the distillation process and whether it can be applied to smaller models for deployment on limited compute.

## 2. Evaluating Semantic and Spatial Guidance for Foundation Model Segmentation of Small-Scale PV in Remote Sensing Imagery

- arXiv ID: `2608.10801`
- Authors: Roni Blushtein-Livnon , Tal Svoray , Osher Rafaeli , Michael Dorman , Itay Fischhendler , Havazelet Yahel , Emir Galilee
- Score: 7
- Link: https://arxiv.org/abs/2608.10801
- PDF: https://arxiv.org/pdf/2608.10801
- Subjects: Computer Vision and Pattern Recognition (cs.CV)
- Reason: Evaluates vision-language foundation models for small object segmentation in remote sensing, directly relevant to astronomical source detection and classification. The prompting strategies and data efficiency insights could transfer to JWST or survey imagery.

Short digest:
The paper asks how different prompting strategies (textual, geometric, hybrid) affect segmentation of small-scale solar panels in remote sensing imagery using SAM3. It finds that spatial guidance (geometric prompts) substantially improves accuracy over textual prompts, and hybrid prompting is best. For astronomy, this suggests that using spatial priors (e.g., coordinates or masks) with foundation models could improve detection of small sources like high-redshift galaxies or little red dots. One could try this on JWST images with point-source or extended-source prompts. A caveat is that the study is on aerial imagery, so transfer to astronomical data needs validation.

Full-text inspection checklist:
- Check whether the prompting strategies are applicable to astronomical images with different noise and background.
- Look for details on how many annotated samples are needed for good performance, which is relevant for limited labeled data.
- See if the model can handle multi-band or multi-wavelength inputs, as JWST data are often multi-filter.

## 3. REATS: LLM Reasoning-based Ensemble Learning for Adaptive Time Series Forecasting

- arXiv ID: `2608.10149`
- Authors: Xu Zhang , Chang Xu , Hui Sun , Nan Ma , Zijian Zhang , Peng Wang , Wei Wang , Li Zhao
- Score: 6
- Link: https://arxiv.org/abs/2608.10149
- PDF: https://arxiv.org/pdf/2608.10149
- Subjects: Machine Learning (cs.LG)
- Reason: The paper uses LLM reasoning for ensemble forecasting, which could transfer to time-series analysis in astronomy (e.g., light curves or photometric data). However, it is not directly astronomical and lacks multimodal or survey-specific focus.

Short digest:
The paper addresses the problem that no single time-series forecasting model works for all data, and proposes an LLM-based ensemble router that combines textual pattern descriptions with numerical features to produce interpretable, sample-adaptive weights. The main idea is to use chain-of-thought reasoning in an LLM to decide which forecasting model to trust for each sample, with a structured input pipeline and fine-tuning. For astronomy, this could help combine multiple models for light-curve or variability analysis, but the method is generic and not tested on astronomical data. A concrete workflow might be applying it to multi-wavelength light curves to improve classification or prediction. Before investing time, check if the method scales to long, irregularly sampled astronomical time series and whether the textual descriptions are feasible for large surveys.

Full-text inspection checklist:
- Check if the method handles irregularly sampled or missing data, common in astronomical time series
- Look for details on how textual pattern descriptions are generated and whether they can be automated for large datasets
- Evaluate the transfer learning results to see if the method generalizes to unseen model types, which is relevant for diverse survey data

## 4. EvoMem: Memory-Augmented Evolution for Code Optimization

- arXiv ID: `2608.10795`
- Authors: Viktor Volkov , Valentin Khrulkov , Andrey V. Galichin , Danil Sivtsov , Nikita Glazkov , Olga Volkova , Konstantin Pchelin , Iaroslav Bespalov , Dmitry V. Dylov , Petr Anokhin , Ivan Oseledets
- Score: 6
- Link: https://arxiv.org/abs/2608.10795
- PDF: https://arxiv.org/pdf/2608.10795
- Subjects: Artificial Intelligence (cs.AI) ; Neural and Evolutionary Computing (cs.NE)
- Reason: Focuses on LLM-driven evolutionary code optimization with memory reuse, which could transfer to automated scientific workflows like optimizing data-reduction or fitting code. Not astronomy-specific but the idea of persistent memory for search could inspire research-agent designs.

Short digest:
The paper asks whether successful mutation strategies in LLM-based evolutionary program search can be reused across runs and tasks. It introduces EvoMem, a persistent memory that stores successful mutation ideas and retrieves them to guide future mutations. This could matter for astronomy by enabling automated tools that learn from past data-analysis or modeling attempts. One could imagine using it to optimize a photometric redshift or SED-fitting code across many datasets. A caveat is that gains vary by task, so it may not always improve performance.

Full-text inspection checklist:
- Check whether memory retrieval is based on task context or program structure, and how relevant it would be to astronomy code.
- Look for benchmarks that resemble scientific or numerical optimization, not just geometric or QA tasks.
- See if the method requires a large number of runs to build useful memory, which may be costly for astronomy workflows.

However, the method is trained on medical data and may need adaptation.
