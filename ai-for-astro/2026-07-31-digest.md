## 2. Rehearse: Stepping Back from the Confidence Cliff in Self-Improving Autoresearch

- arXiv ID: `2607.27687`
- Authors: Jiazhen Ji , Shouhong Ding
- Score: 7
- Link: https://arxiv.org/abs/2607.27687
- PDF: https://arxiv.org/pdf/2607.27687
- Subjects: Artificial Intelligence (cs.AI)
- Reason: The paper directly addresses self-improving autoresearch loops, which are highly relevant to automated scientific discovery and research agents for astronomy.

Short digest:
This paper studies the reliability of pre-execution judgment in autoresearch loops, where an agent proposes code changes and runs training jobs. The main finding is that the agent's ability to predict whether a modification will help declines over iterations, a 'confidence cliff'. The proposed Rehearse skill improves late selective accuracy by using focused memory of past attempts. This matters for astronomy because it could improve the efficiency of automated pipelines that iteratively improve data analysis code. The workflow would be to apply Rehearse to an autoresearch loop that optimizes photometric redshift estimation or source classification. The limitation is that it requires a training-run budget and a well-defined metric to optimize.

Full-text inspection checklist:
- Check if the method is tested on scientific or astronomical code optimization
- Look for details on how the focused memory is implemented and its computational cost

Short digest:

This matters for astronomy because research agents analyzing JWST data could benefit from dynamically reorganizing subtasks (e.g., source detection, SED fitting, literature search) based on intermediate results. I could imagine applying MANTA to a multi-agent pipeline for classifying little red dots, where agents for imaging, spectral fitting, and literature review adapt their collaboration based on data complexity. However, the paper's benchmarks are generic (information seeking, planning), so I should check whether the topology updates are interpretable and controllable enough for scientific workflows.

Full-text inspection checklist:

- Look for details on how task-conditioned topology initialization works and whether it requires domain-specific priors
