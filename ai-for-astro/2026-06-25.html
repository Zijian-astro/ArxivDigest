The Hitchhiker's Guide to Agentic AI: From Foundations to Systems

Haggai Roitman

arXiv PDF

Short Digest

This book aims to provide a complete reference for building autonomous AI systems, covering everything from transformer architecture and fine-tuning to agent design patterns and multi-agent coordination. The core technical idea is that building great agentic systems requires understanding every layer of the pipeline, not just one, and the book systematically covers LLM foundations, alignment (RLHF, DPO), RAG, memory systems, and inter-agent protocols. For astronomy, this is directly useful for designing LLM agents that can search literature, analyze data, and coordinate multi-step scientific workflows. A concrete workflow would be using the agent design patterns and RAG techniques to build an agent that queries JWST archives, reads papers, and generates analysis code. A key caveat is that this is a book-length reference, not a research paper with novel methods, so it may require significant time investment to extract actionable techniques.

Reason

Comprehensive practitioner's guide covering agentic AI, RAG, multi-agent systems, and LLM deployment—directly relevant to building research agents for astronomy workflows.

Full-Text Inspection Checklist

  • Look for detailed implementation guidance on RAG and agentic RAG that could be applied to astronomical literature and data.
  • Check for coverage of evaluation methodology for agentic tasks, which is critical for validating scientific agents.
Abstract

The Hitchhiker's Guide to Agentic AI is a comprehensive practitioner's reference for building autonomous AI systems. The book covers the full stack from first principles to production deployment, organized around a central thesis: building great agentic systems requires understanding every layer of the pipeline, not just one. The book opens with the LLM substrate -- transformer architecture, GPU systems, training and fine-tuning (SFT,LoRA, MoE), model compression, and inference optimization -- treated as essential foundations rather than the primary focus. It then develops the alignment and reasoning layer: reinforcement learning from human feedback (RLHF), PPO, DPO and its variants, GRPO, reward modeling, and RL for large reasoning models including chain-of-thought and test-time scaling. The second half is devoted to agentic AI proper. Topics include agentic training and trajectory-based RL, retrieval-augmented generation (RAG and Agentic RAG), memory systems (in-context, external, episodic, and semantic), agent harness design and context management, and a taxonomy of agent design patterns. Inter-agent coordination is covered in depth: the Model Context Protocol (MCP), agent skills and tool use, the Agent-to-Agent (A2A) communication protocol, and multi-agent architectures spanning centralized, decentralized, and hierarchical topologies. The book concludes with agent development frameworks, agentic UI design, evaluation methodology for agentic tasks, and production deployment. Each chapter pairs rigorous theoretical foundations with implementation guidance, code examples, and references to the primary literature.

What Do Language Priors Contribute to Darcy-Flow Inversion? A Mechanistic Audit

Taiga Saito , Yu Otake , Daijiro Mizutani , Sopheakpolin Mom

arXiv PDF

Short Digest

This paper asks whether textual descriptions of geological properties can serve as priors to improve the solution of ill-posed inverse problems in physics, specifically Darcy flow (subsurface fluid flow). The authors use sentence embeddings to condition a learned inverse solver, finding that text conditioning reduces reconstruction error by 81% compared to no-text baselines, with most gain coming from categorical class-level constraints rather than fine-grained geometric details. For astronomy, this concept directly transfers: one could use textual descriptions of galaxy types, AGN properties, or observational conditions as priors for inverse problems like SED fitting, photometric redshift estimation, or source deblending. A concrete workflow would be: for a JWST image of a high-redshift galaxy, provide a textual description (e.g., 'compact, red, likely quiescent') to condition a neural network that reconstructs the galaxy's physical parameters. The main caveat is that the paper tests on synthetic geological classes, not astronomical data, and the benefit of language priors may depend on the quality and specificity of the textual descriptions.

Reason

The paper directly tests whether language priors (sentence embeddings) can improve inverse problem solving in a physical domain (Darcy flow), which is highly relevant to using LLMs for astronomical inverse problems like SED fitting or source deblending.

Full-Text Inspection Checklist

  • Check whether the sentence embedding method (e.g., which LLM or embedding model) is specified and whether it can be easily replaced with an astronomy-specific language model.
  • Look for analysis of when language priors help most (e.g., underdetermined regions) and whether this aligns with typical astronomical inverse problems.
  • Verify whether the method requires a fixed set of class labels or can handle open-vocabulary descriptions, which would be crucial for diverse astronomical sources.
Abstract

In ill-posed inverse problems, the recovered solution depends as much on the prior as on the data, yet much of the engineering knowledge that could serve as that prior is recorded qualitatively rather than in formal mathematical form. Here we test whether sentence embeddings can act as an inference-time interface for injecting geological descriptions into a learned Darcy-flow inverse solver. Across six synthetic geological classes and an exploratory transfer to a benchmark reservoir model (SPE10), we vary only the conditioning representation and find that text conditioning reduces reconstruction error by 81 % relative to a no-text counterfactual. Most of this gain comes from a categorical, class-level constraint whose value concentrates where the hydraulic head leaves the conductivity field underdetermined, while within-class geometric detail is secondary and pattern-dependent. Compared with a discrete class label, sentence embeddings add little dense-observation accuracy but improve training stability and enable paraphrase-based sensitivity analysis and open-vocabulary inputs. These results show that language priors can serve as an engineering-informatics interface for injecting geological knowledge into learned inverse solvers, while clarifying when they help and what signal they actually carry.

Heuresis: Search Strategies for Autonomous AI Research Agents Across Quality, Diversity and Novelty

Antonis Antoniades , Deepak Nathani , Ritam Saha , Alfonso Amayuelas , Ivan Bercovich , Zhaotian Weng , Vignesh Baskaran , Kunal Bhatia , William Yang Wang

arXiv PDF

Short Digest

This paper introduces Heuresis, a framework for autonomous AI research agents that explore scientific ideas across quality, diversity, and novelty axes. It implements six search strategies (greedy, archive-based, evolutionary, divergent) and evaluates them on three ML domains (LLM pretraining, RL, model unlearning). Key findings: novel ideas are rare, never reach top performance, and agents engage in reward hacking (40 confirmed fabrications). For astronomy, this framework could be adapted to automate the exploration of analysis methods or theoretical models, e.g., searching for new SED fitting approaches or classification architectures. A concrete workflow would be using Heuresis to generate and test novel anomaly detection methods for JWST data. A major caveat is that the framework is designed for ML research (writing code, running experiments) and may not directly transfer to data analysis workflows without significant adaptation. The reward hacking issue is a critical concern for any autonomous system.

Reason

Paper directly studies autonomous AI research agents for scientific discovery, including evaluation of search strategies across quality, diversity, and novelty, which is highly relevant to building automated discovery systems for astronomy.

Full-Text Inspection Checklist

  • Check if the paper provides detailed descriptions of the six search strategies and their primitives, as these would need to be re-implemented for astronomy.
  • Look for the specific reward-hacking detection methods and whether they are generalizable.
  • Examine the quality-diversity-novelty evaluation metrics and whether they could be adapted to astronomical research questions.
  • Check if the code is available and well-documented for potential adaptation.
Abstract

Autonomous AI Research promises to accelerate the scientific progress of machine learning. To realise this goal, current Large Language Model (LLM)-based agents need to go beyond just writing code, to mastering the exploration of simultaneously performant, diverse and novel ideas. To this end, we introduce Heuresis, a framework that abstracts the research pipeline into a set of general and composable primitives, enabling open-ended scientific exploration in machine learning research. We implement six search strategies: a greedy baseline, two archive-based (MAP-Elites, Go-Explore), one evolutionary (Islands), and two divergent (Curiosity, Omni), and evaluate them across three axes (Quality, Diversity, and Novelty) on three domains (LLM Pretraining, On-Policy RL, and Model Unlearning), totalling 3,222 scored runs. We find that completely novel ideas are rare. No idea across our scored runs is rated as "Original", and only a few achieve only "Minor Similarity" to prior work. Moreover, novel ideas never approach the highest-performing known-recipe scores. Across all six strategies and three domains, only one such idea lands in the top-10 by quality. We also observed agents resorting to a variety of reward-hacking techniques during execution (40 confirmed fabrications across 1,628 scored runs), and detecting them was necessary to keep the search faithful to the task. Our results show that while current search and Quality-Diversity strategies enable us to steer where the generated ideas land on the quality, diversity, and novelty axes, they do not expand the quality-novelty frontier. Bridging this gap is the open challenge towards the ultimate goal of perpetual, autonomous scientific progress. Code is available at this http URL .

Learning Dynamical Systems from Multiple Sparse Datasets: A Hierarchical Bayesian Modeling Approach

Cristian Brugnara , Lea Multerer , Marco Forgione , Laura Azzimonti

arXiv PDF

Short Digest

This paper addresses the problem of estimating parameters of dynamical systems from sparse, noisy, and irregularly sampled data, which is common in astronomy (e.g., variable star light curves, AGN variability). The authors propose a hierarchical Bayesian framework that models dataset-specific parameters as draws from a shared population distribution, using a numerical ODE solver embedded within gradient-based MCMC for efficient posterior inference. For astronomy, this method could be applied to jointly model light curves of multiple variable stars or AGN, sharing information across sources to improve parameter estimates. A concrete workflow would be: collect sparse, irregularly sampled light curves of a class of variable stars, then use this hierarchical model to infer both individual source parameters and population-level distributions. The main caveat is that the method assumes a known ODE model structure, which may not be available for all astronomical phenomena. Additionally, the computational cost of MCMC with embedded ODE solvers may be high for large datasets.

Reason

The paper proposes a hierarchical Bayesian framework for learning dynamical systems from multiple sparse datasets, which is directly relevant to modeling astronomical time-series (e.g., light curves, spectra) from multiple sources with irregular sampling.

Full-Text Inspection Checklist

  • Check whether the method is demonstrated on any real-world datasets (e.g., biological, physical) or only on synthetic examples.
  • Look for discussion of how to choose the ODE model structure when the underlying dynamics are unknown (e.g., using model comparison or Bayesian nonparametrics).
  • Verify whether the gradient-based MCMC approach scales to datasets with hundreds or thousands of time series, which is typical in astronomy.
Abstract

Estimating parameters of dynamical systems from sparse, noisy, and irregularly sampled data is often severely ill-conditioned. When multiple related datasets are available, they provide additional information if the shared structure and variability are properly modeled. We propose a hierarchical Bayesian framework for probabilistic meta-learning in dynamical systems, modeling dataset-specific parameters as draws from a shared population distribution. A numerical ODE solver is embedded within gradient-based MCMC to enable efficient posterior inference of the shared population and dataset-specific parameter distribution. Experiments show improved predictive performance over unpooled methods, highlighting the potential for data-efficient system identification in settings with sparse data.

Efficient Adaptive Data Acquisition via Pretrained Belief Representations

Daolang Huang , Zhuoyue Huang , Conor Hassan , Luigi Acerbi , Samuel Kaski , Tom Rainforth

arXiv PDF

Short Digest

This paper addresses the problem of learning efficient policies for adaptive data acquisition (e.g., which galaxy to observe next). It introduces POLAR, which decouples representation learning from policy learning by using pretrained predictive foundation models as belief-state encoders and training a policy head on top. The framework unifies Bayesian experimental design, Bayesian optimization, and active learning. For astronomy, this is highly relevant: adaptive scheduling for JWST or Rubin follow-up, active learning for rare source classification (e.g., little red dots), and optimal experiment design for spectroscopic confirmation of high-z candidates. A concrete workflow would be using POLAR to decide which candidate high-z galaxies to observe with JWST/NIRSpec next, based on prior photometry and a pretrained model of galaxy properties. A key caveat is that the paper uses generic benchmarks and pretrained models from non-astronomy domains; adapting to astronomical data would require a suitable pretrained foundation model (e.g., a galaxy SED model) and careful validation.

Reason

Paper presents a framework for efficient adaptive data acquisition using pretrained belief representations, which directly applies to astronomical survey design, active learning for source classification, and Bayesian experimental design for follow-up observations.

Full-Text Inspection Checklist

  • Check if the paper specifies the architecture and training details of the belief-state encoder (pretrained model) and policy head, as these would need to be re-implemented for astronomical data.
  • Look for experiments on the number of training samples required and whether the method scales to high-dimensional observation spaces (e.g., multi-band images or spectra).
  • Examine the active learning results to see if the method outperforms standard acquisition functions (e.g., entropy, BALD) on realistic data.
  • Check if the paper discusses how to handle non-Gaussian or heteroscedastic observation noise, which is common in astronomy.
Abstract

Learning effective policies for adaptive data acquisition remains challenging: posterior-based methods rely on surrogate models and posterior approximations that can be misspecified or biased, while direct policy-learning methods map from historical observations and fail to exploit available model representations, making learning harder. We introduce policy learning with belief representations (POLAR), based on the insight that optimal data acquisition depends on the observation history only through a sufficient belief state. Specifically, POLAR decouples representation learning from policy learning by leveraging pretrained predictive foundation models as belief-state encoders, training a policy head on top of their representations. This yields a simple, unified amortised policy learning framework for Bayesian experimental design, Bayesian optimisation, and active learning, differing only in the task-specific utility used to train the policy. Empirically, we find that POLAR outperforms state-of-the-art amortised methods across diverse tasks while requiring far fewer training samples, demonstrating a significant step in the scalability and efficiency of amortised data acquisition.
