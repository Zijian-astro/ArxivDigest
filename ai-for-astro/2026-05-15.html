Towards Self-Evolving Agentic Literature Retrieval

Yuwen Du , Tian Jin , Jing Kang , Xianghe Pang , Jingyi Chai , Tingjia Miao , Fenyi Liu , WenHao Wang , Sikai Yao , Yuzhi Zhang , Siheng Chen

arXiv PDF

Short Digest

This paper aims to solve the problem of literature retrieval for scientific research, where traditional keyword search fails to capture complex intents and LLMs hallucinate. It introduces PaSaMaster, a self-evolving agentic system that iteratively refines search intents, retrieves papers, and ranks them by relevance with evidence-grounded recommendations. The system uses a frontier LLM only for intent understanding, while large-scale retrieval is done with lightweight models, achieving zero source hallucination. For astronomy, this could be used to automatically find papers relevant to specific JWST observations, high-redshift galaxy studies, or AGN classification, by iteratively refining search queries based on initial results. The system outperforms GPT-5.2 at 1% of the cost, making it practical for routine use. However, the benchmark covers 38 scientific disciplines but does not specifically test on astronomy literature.

Reason

Directly addresses automated literature retrieval for scientific research, with a self-evolving agentic system that could be applied to astronomy literature review and discovery.

Full-Text Inspection Checklist

  • Look for the evaluation on astronomy-specific queries or papers to assess domain coverage.
  • Check the ranking algorithm to see if it can handle domain-specific relevance criteria (e.g., instrument, redshift range, methodology).
  • See if the system can be customized with astronomy-specific corpora (e.g., NASA ADS, arXiv astro-ph).
  • Examine the evidence-grounded recommendations to ensure they provide useful citations and reasoning for astronomy papers.
Abstract

As large language models reshape scientific research, literature retrieval faces a twofold challenge: ensuring source authenticity while maintaining a deep comprehension of academic search intents. While reliable, traditional keyword-centric search fails to capture complex research intents. Frontier LLMs can handle complex research intents, but their high cost and tendency to hallucinate remain key limitations. Here we introduce PaSaMaster, a self-evolving agentic literature retrieval system that produces relevance-scored paper rankings with evidence-grounded recommendations through iterative intent analysis, retrieval, and ranking. It is built on three key designs. First, it transforms literature retrieval from a one shot query--document matching problem into a search process that evolves over time, using ranked evidence to reveal gaps, refine intents, and guide follow-up searches. Second, it prevents hallucinated sources by treating retrieval as intent--paper relevance ranking rather than generation. Finally, PaSaMaster improves cost efficiency by separating planning from retrieval: a frontier LLM is used only for intent understanding, while large scale retrieval and relevance scoring are delegated to customized corpora and lightweight models. Evaluated on the PaSaMaster Benchmark across 38 scientific disciplines, our system exposes the severe inaccuracy and incompleteness of traditional keyword retrieval (improving F1-score by 15.6X) and the unreliability of generative LLMs (which exhibit hallucination rates up to 37.79%). GEAR: Genetic AutoResearch for Agentic Code Evolution

Ahmadreza Jeddi , Minh Ngoc Le , Hakki C. Karaimer , Konstantinos G. Derpanis , Babak Taati

arXiv PDF

Short Digest

This paper addresses the problem that autonomous research agents often use a narrow single-path search strategy that discards useful partial ideas. The authors propose GEAR, which maintains a population of candidate solutions and uses mutation and crossover to explore new ideas, similar to genetic algorithms. For astronomy, this could be used to automatically explore different analysis pipelines for JWST data, such as testing multiple SED fitting models or source classification methods. A concrete workflow could be using GEAR to autonomously search over hyperparameters and model architectures for photometric redshift estimation or anomaly detection in survey data. A key caveat is that GEAR is demonstrated on machine learning experiment optimization, not directly on astronomical data, so adaptation would be needed.

Reason

This paper presents an autonomous research agent that uses population-based search over multiple research states, which is directly relevant to automated scientific discovery for astronomy.

Full-Text Inspection Checklist

  • Check if the method is demonstrated on any scientific or astronomical dataset.
  • Look for details on how the search space is defined and how candidate solutions are represented.
  • Check if the paper discusses transferability to other domains like astronomy.
Abstract

Autonomous research agents can already run machine learning experiments without human supervision, but many rely on a narrow search strategy: they repeatedly modify one program and keep changes only when they improve the current best result. This can cause them to discard useful partial ideas, alternative promising directions, and insights from failed or incomplete experiments. GEAR, or Genetic AutoResearch, replaces this single-path search with a population-based search over multiple research states. It keeps a set of strong candidate solutions, selects parents based on productivity, novelty, and coverage, and explores new ideas through mutation and crossover. Each research state stores its code changes, reflections, and performance data, allowing future decisions to build on past discoveries. The paper studies three versions of GEAR: one controlled through prompting, one using a fixed programmatic search controller, and one where the controller itself can evolve during the run. Under the same compute budget and environment, all three versions outperform the AutoResearch baseline. More importantly, while the baseline tends to settle into one local optimum, GEAR continues finding improvements over longer runs. Overall, the results suggest that autonomous research agents become more effective when they maintain multiple promising directions and can adapt their search strategy over time.

Collider-Bench: Benchmarking AI Agents with Particle Physics Analysis Reproduction

Darius A. Faroughy , Sofia Palacios Schweitzer , Ian Pang , Siddharth Mishra-Sharma , David Shih

arXiv PDF

Short Digest

This paper introduces Collider-Bench, a benchmark for evaluating whether LLM agents can reproduce experimental analyses from the Large Hadron Collider using only public papers and open scientific software. Each task requires the agent to turn a published analysis into an executable simulation-and-selection pipeline and submit predicted collision event yields. Agents must use physical reasoning, domain knowledge, and trial-and-error to fill gaps in the public toolchain and published papers. This is directly relevant to astronomy because the same approach could be applied to reproducing JWST or HST data analysis pipelines from papers. For example, an agent could be tasked with reproducing a high-redshift galaxy SED fitting analysis from a published paper. The benchmark provides a template for evaluating research agents on real scientific workflows. Limitations include the domain-specific nature of particle physics and the need for domain adaptation to astronomy.

Reason

This benchmark evaluates LLM agents on reproducing particle physics analyses, directly relevant to automated scientific discovery and research agents for astronomy.

Full-Text Inspection Checklist

  • Check if the benchmark framework is extensible to astronomy analyses (e.g., JWST data reduction, SED fitting).
  • Look for the evaluation metrics and whether they could be adapted to astronomical histogram comparisons (e.g., flux distributions).
  • Examine the LLM judge for qualitative failure modes and whether it could detect hallucinations in astronomical reasoning.
Abstract

Autonomous language-model agents are increasingly evaluated on long-horizon tool-use tasks, but existing benchmarks rarely capture the complexity and nuance of real scientific work. To address this gap, we introduce Collider-Bench, a benchmark for evaluating whether LLM agents can reproduce experimental analyses from the Large Hadron Collider (LHC) using only public papers and open scientific software. Such analyses are often difficult to reproduce because the public toolchain only approximates the software used internally by the experimental collaborations, while the published papers inevitably omit implementation details needed for a faithful reconstruction. Agents must therefore rely on physical reasoning, domain knowledge, and trial-and-error to fill these gaps. Each task requires the agent to turn a published analysis into an executable simulation-and-selection pipeline and submit predicted collision event yields in specified signal regions. These predictions are evaluated with standard histogram metrics that provide continuous fidelity scores without a hand-written rubric. We also report the computational cost incurred by each agent per task. Finally, we evaluate the codebase and full session trace using an LLM judge to catch qualitative failure modes such as fabrications, hallucinations and duplications. We release an initial set of tasks drawn from LHC searches, together with a containerized sandbox and event simulation tools. We evaluate across a capability ladder of general purpose coding agents. Our results show that on average no agent reliably beats the physicist-in-the-loop solution.

Physics-R1: An Audited Olympiad Corpus and Recipe for Visual Physics Reasoning

Shan Yang

arXiv PDF

Short Digest

This paper audits multimodal physics evaluation pipelines and documents train-eval contamination, translation drift, and MCQ saturation. It releases a cleaned corpus, a held-out olympiad evaluation set, and a reference recipe (Physics-R1) that lifts performance on open-ended physics reasoning. The recipe uses reinforcement learning (GSPO+DAPO) cold-started from a vision-language model. For astronomy, this is directly relevant because it provides a methodology for building and evaluating AI systems that reason about physics from images and text. The rigorous auditing approach could be applied to astronomical benchmarks. A key limitation is that the physics problems are olympiad-style, not astronomical, and the transfer to astronomical reasoning tasks is not demonstrated.

Reason

Directly addresses multimodal physics reasoning with a rigorous evaluation pipeline, highly relevant for automated scientific discovery in astronomy.

Full-Text Inspection Checklist

  • Look for the auditing methodology to apply to astronomical benchmarks
  • Check if the Physics-R1 recipe could be adapted to astronomical visual reasoning tasks
  • Examine the evaluation metrics for open-ended reasoning that could be used for astronomical source classification or interpretation
Abstract

We audit the multimodal-physics evaluation pipeline end-to-end and document three undetected construction practices that distort how the field measures vision-language reasoning: train-eval contamination, translation drift, and MCQ saturation. (1) Public training pools (UGPhysics-Train, SciInstruct, MMK12) pass single-stage 5-gram-Jaccard audits with zero hits across all six public physics evals; a three-stage audit (Jaccard -> mxbai-embed-large cosine -> Haiku-4.5 LLM-judge) surfaces 134 near-duplicates and 4,846 paraphrase candidates in SciInstruct alone. (2) A 17-pp Sonnet 4.5 delta on 59 paired Estonian-English olympiad problems (30.5% vs. 13.6%; sign test p=0.011, McNemar p=0.021, paired bootstrap 95% CI [+5.1, +28.9] pp). (3) A 46-pp format-and-novelty gradient on identical Sonnet weights between MCQ (79.7% on PhyX) and open-ended olympiad evaluation (33.4% on PhysOlym-A). We release four artifacts addressing these gaps: PhysCorp-A (6,432-record three-stage-audited multimodal corpus), PhysR1Corp (2,268-record closed-form RL pool), PhysOlym-A (500-problem, 99.8% novel-source held-out olympiad eval with native difficulty labels and an EN/ET bilingual subset), and Physics-R1, a reference GSPO+DAPO recipe cold-started from Qwen3-VL-8B-Thinking. Across 3 seeds, Physics-R1 lifts the audited corpus over the 8B base by +18.3 pp on PhysOlym-A liberal (8.0 -> 26.3 +/- 1.7; 7.1 pp behind Sonnet 4.5), +15.7 pp on PhysReason (23.9 -> 39.6 +/- 6.4; ahead of Qwen3-VL-32B and Gemini 2.5 Pro), +6.9 pp on OlympiadBench-Physics (46.2 +/- 1.5), and +4.1 pp on PhyX MCQ (77.8 +/- 0.3).

MetaAgent-X : Breaking the Ceiling of Automatic Multi-Agent Systems via End-to-End Reinforcement Learning

Yaolun Zhang , Yujie Zhao , Nan Wang , Yiran Wu , Jiayu Chang , Yizhao Chen , Qingyun Wu , Jishen Zhao , Huazheng Wang

arXiv PDF

Short Digest

This paper tackles the problem of automatically designing and executing multi-agent systems without manual orchestration. It introduces MetaAgent-X, an end-to-end reinforcement learning framework that jointly optimizes both the agent designer and the execution agents. This matters for astronomy because it could enable automated scientific discovery systems that design their own analysis pipelines. For example, one could imagine a system that automatically spawns specialized agents for JWST data reduction, source detection, and SED fitting, then coordinates them. However, the method is demonstrated on general NLP tasks, so its transfer to astronomy-specific tools and APIs remains unvalidated.

Reason

Directly addresses automated multi-agent systems and end-to-end RL for agent design, which is highly relevant to building research agents for astronomy workflows.

Full-Text Inspection Checklist

  • Check whether the framework supports integration with astronomy-specific APIs and tools (e.g., astropy, JWST pipeline).
  • Look for ablation studies showing how the designer and executor co-evolve, and whether the method scales to many agents.
Abstract

Automatic multi-agent systems aim to instantiate agent workflows without relying on manually designed or fixed orchestration. However, existing automatic MAS approaches remain only partially adaptive: they either perform training-free test-time search or optimize the meta-level designer while keeping downstream execution agents frozen, which creating a frozen-executor ceiling and leaving the end-to-end training of self-designing and self-executing agentic models unexplored. To address this, we introduce MetaAgent-X, an end-to-end reinforcement learning framework that jointly optimizes automatic MAS design and execution. MetaAgent-X enables script-based MAS generation, execution rollout collection, and credit assignment for both designer and executor trajectories. To support stable and scalable optimization, we propose Executor Designer Hierarchical Rollout and Stagewise Co-evolution to improve training stability and expose the dynamics of designer-executor co-evolution. MetaAgent-X consistently outperforms existing automatic MAS baselines, achieving up to 21.7% gains. Comprehensive ablations show that both designer and executor improve throughout training, and that effective automatic MAS learning follows a stagewise co-evolution process. These results establish end-to-end trainable automatic MAS as a practical paradigm for building self-designing and self-executing agentic models.

SciPaths: Forecasting Pathways to Scientific Discovery

Eric Chamoun , Yizhou Chi , Yulong Chen , Rui Cao , Zifeng Ding , Michalis Korakakis , Andreas Vlachos

arXiv PDF

Short Digest

This paper introduces discovery pathway forecasting: given a target scientific contribution, identify the enabling contributions and ground them in prior work. It presents SciPaths, a benchmark of 262 expert-annotated pathways from ML/NLP papers. The best model achieves only 0.189 F1, showing this is a hard problem. For astronomy, this could help map the dependencies needed to achieve a breakthrough (e.g., detecting biosignatures with JWST). A concrete workflow: using an LLM agent to propose a pathway for a new high-redshift galaxy analysis method. Caveat: the benchmark is limited to ML/NLP; astronomy-specific pathways would need new annotations.

Reason

Directly addresses scientific discovery pathway forecasting, which is core to automated scientific discovery and research agents.

Full-Text Inspection Checklist

  • Look for the annotation guidelines and whether they can be adapted to astronomy.
  • Check the evaluation metrics (F1 under strict semantic matching) and whether they capture partial credit.
  • Examine the types of enabling contributions (method, data, theory) and their distribution.
Abstract

Scientific progress depends on sequences of enabling contributions, yet existing AI4Science benchmarks largely focus on citation prediction, literature retrieval, or idea generation rather than the dependencies that make progress possible. In this paper, we introduce discovery pathway forecasting: given a target scientific contribution and the prior literature available at a specified time, the task is to (1) identify the enabling contributions required to realize it and (2) ground each in prior work when such prior work exists. We present SciPaths, a benchmark of 262 expert-annotated gold pathways and 2,444 silver pathways constructed from machine learning and natural language processing papers, where each pathway records enabling contributions, roles, rationales, and prior-work groundings or unmapped decisions. Evaluating frontier and open-weight language models, we find that the best model reaches only 0.189 F1 under strict semantic matching, with core methodological dependencies hardest to recover. Prior-work grounding improves substantially when gold enabling contributions are provided, showing that decomposition quality is a major bottleneck for end-to-end pathway recovery. SciPaths therefore shifts evaluation toward a missing capability in scientific forecasting: reasoning backward from a target contribution to the enabling scientific building blocks and prior-work dependencies that make it feasible.

Case-Based Calibration of Adaptive Reasoning and Execution for LLM Tool Use

Renning Pang , Tian Lan , Leyuan Liu , Piao Tong , Sheng Cao , Xiaosong Zhang

arXiv PDF

Short Digest

This paper tackles the problem of making LLMs more reliable when they call external tools or functions, a key capability for autonomous scientific agents. The authors propose CAST, a framework that learns from past tool-use trajectories to decide when to reason deeply and when to execute quickly, without needing to retrain the model. Instead of copying past examples, CAST extracts complexity and failure signals from historical runs to guide the model's reasoning strategy. For astronomy, this could mean building an agent that reliably queries databases, runs SED-fitting code, or calls JWST pipeline tools without making structural errors. A concrete workflow would be an agent that retrieves spectra from MAST, runs fitting, and returns results, where CAST could reduce errors from malformed API calls or missing parameters. The main caveat is that the method is evaluated on general tool-use benchmarks (BFCLv2, ToolBench), not on astronomy-specific tools, so transfer is plausible but unproven.

Reason

Directly addresses LLM tool use and execution reliability, which is central to building LLM agents for scientific workflows. The case-based calibration approach could transfer to astronomical data analysis pipelines.

Full-Text Inspection Checklist

  • Check whether the case library can be seeded with astronomy-specific tool trajectories or requires generic data.
  • Look for the definition of 'structural errors' and whether they map to common mistakes in astronomical tool use (e.g., wrong column names, missing filters).
  • Examine the reward design: is it task-agnostic or would it need to be redefined for astronomy workflows?
Abstract

Tool use extends large language models beyond parametric knowledge, but reliable execution requires balancing appropriate reasoning depth with strict structural validity. We approach this problem from a case-based perspective to present CAST, a case-driven framework that treats historical execution trajectories as structured cases. Instead of reusing raw exemplar outputs, CAST extracts case-derived signals to identify complexity profiles for estimating optimal reasoning strategies, alongside failure profiles to map likely structural breakdowns. The framework translates this knowledge into a fine-grained reward design and adaptive reasoning, enabling the model to autonomously internalize case-based strategies during reinforcement learning. Experiments on BFCLv2 and ToolBench demonstrate that CAST improves both schema-faithful execution and task-level tool-use success while reducing unnecessary deliberation. The approach achieves up to 5.85 percentage points gain in overall execution accuracy and reduces average reasoning length by 26%, significantly mitigating high-impact structural errors. Ultimately, this demonstrates how historical execution cases can provide reusable adaptation knowledge for calibrated tool use.
