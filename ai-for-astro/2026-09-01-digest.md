- Score: 8
- Link: https://arxiv.org/abs/2608.30392
- PDF: https://arxiv.org/pdf/2608.30392
- Subjects: Machine Learning (cs.LG)
- Reason: Directly relevant to foundation models for Earth observation and tabular data, with insights on modality gaps that apply to astronomical surveys. The discussion of task-specific adaptation is useful for JWST data.

Short digest:
This paper investigates why Earth observation foundation models underperform in agricultural tasks, identifying a pretraining-deployment modality gap. The main claim is that these models struggle with non-imagery data modalities and task-specific nuances, leading to unstable rankings. For astronomy, this highlights the need for multimodal foundation models that handle catalogs, spectra, and images together, as in JWST analysis. A concrete workflow could be evaluating foundation models on galaxy classification using both images and photometric catalogs. The paper's caveat is that it focuses on agriculture, but the structural analysis transfers to astronomy.

- Look for the five structural axes that define task space, to see if they map to astronomical tasks.

## 2. DS-Lighting: Making Agent Harnesses Explicit for Data-Science Automation

- arXiv ID: `2608.28590`
- Authors: Fan Liu , Hao Liu
- Score: 7
- Link: https://arxiv.org/abs/2608.28590
- PDF: https://arxiv.org/pdf/2608.28590
- Subjects: Artificial Intelligence (cs.AI)
- Reason: Directly addresses LLM agents for data-science automation, which is relevant to automated scientific discovery and research workflows. The explicit harness design could transfer to astronomical data analysis pipelines.

Short digest:
The paper tackles the problem that LLM agents for data-science tasks often have implicit, poorly reproducible harnesses. It introduces DS-Lighting, a toolkit that decomposes the harness into data, workflow, execution, and evaluation layers, representing agents as executable operator programs. This matters for astronomy because it could provide a structured way to build reproducible, comparable AI-driven analysis pipelines for large survey data. A concrete workflow could be using DS-Lighting to automate SED fitting or source classification across JWST catalogs. However, the paper focuses on generic data-science benchmarks, so I should check whether the harness supports domain-specific tools and data formats used in astronomy.

Full-text inspection checklist:
- Check if the harness supports custom data loaders or domain-specific file formats (e.g., FITS).
- Look for examples of adaptive search or predefined pipelines that could be adapted to iterative fitting tasks.
- Assess whether the evaluation layer can incorporate domain-specific metrics like photometric redshift accuracy.
