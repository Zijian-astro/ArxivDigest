## 1. EurekAgent: Agent Environment Engineering is All You Need For Autonomous Scientific Discovery

- arXiv ID: `2606.13662`
- Authors: Amy Xin , Jiening Siow , Junjie Wang , Zijun Yao , Fanjin Zhang , Jian Song , Lei Hou , Juanzi Li
- Score: 9
- Link: https://arxiv.org/abs/2606.13662
- PDF: https://arxiv.org/pdf/2606.13662
- Subjects: Artificial Intelligence (cs.AI) ; Computation and Language (cs.CL)
- Reason: Directly addresses autonomous scientific discovery with LLM agents, including environment engineering for reliable research agents, which is highly relevant for astronomy.

Short digest:
This paper argues that the bottleneck for autonomous scientific discovery is no longer agent workflows but the design of agent environments—the resources, constraints, and interfaces that shape agent behavior. It presents EurekAgent, a system that engineers environments along four dimensions: permissions, artifacts, budget, and human-in-the-loop. For astronomy, this could be used to build a research agent that autonomously analyzes JWST data, runs SED fitting, and searches for high-redshift galaxies. The system achieves state-of-the-art results on math and ML tasks with very low API cost. An astronomer would need to design the appropriate environment (tools, data access, evaluation metrics) for their specific discovery task.

Full-text inspection checklist:
- Check whether the paper provides a detailed description of the artifact engineering (filesystem, Git) and how it supports systematic experimentation.
- Look for the specific permissions engineering; see how it prevents reward hacking and ensures safe execution.
- See if the human-in-the-loop engineering is practical for a busy astronomer; does it require constant monitoring or just occasional intervention?

## 2. Benchmarking AI Agents for Addressing Scientific Challenges Across Scales

- arXiv ID: `2606.12736`
- Authors: Tianyu Liu , Allen Xin Wang , Antonia Panescu , Lisa Xinyi Chen , Wenxin Long , Xinyu Wei , Yueqian Jing , Ziyao Zeng , Jihang Chen , Sihan Jiang , Ziqing Wang , Siyi Gu , Siyu Chen , Xinyang Hu , Haoran Shao , Leqi Xu , Wangjie Zheng , Zhiyuan Cao , Ada Fang , Botao Yu , Kunyang Sun , Rex Ying , Arman Cohan , Qingyu Chen , Lingzhou Xue , Kaize Ding , Yuanqi Du , Wengong Jin , Zhuoran Yang , Marinka Zitnik , James Zou , Hua Xu , Hongyu Zhao
- Score: 8
- Link: https://arxiv.org/abs/2606.12736
- PDF: https://arxiv.org/pdf/2606.12736
- Subjects: Artificial Intelligence (cs.AI) ; Machine Learning (cs.LG)
- Reason: Directly evaluates AI agents for scientific discovery, which is a core interest. The benchmark includes tasks across domains and could inform how to build agents for astronomy workflows.

Short digest:
This paper asks how well current AI agents perform on real-world scientific research tasks. The authors introduce SciAgentArena, a benchmark of ~200 tasks with stepwise verification and an interactive environment. They find that agents handle well-specified data-analysis workflows but struggle with generating novel insights and open-ended research. For astronomy, this suggests current agents could assist with routine data reduction or classification but not yet autonomous discovery. A concrete workflow might be using an agent to run a standard SED-fitting pipeline on a JWST catalog. A key caveat is that the benchmark tasks are drawn from multiple domains, so astronomy-specific performance is not isolated.

Full-text inspection checklist:
- Check which scientific domains are included and whether astronomy tasks are present
- Look for examples of well-specified vs. open-ended tasks to gauge transferability to JWST analysis
- Examine the evaluation criteria for data-analysis workflows to see if they match typical astronomy pipelines

## 3. CQC-RAG: Robust Retrieval-Augmented Generation via Cross-Query Consistency

- arXiv ID: `2606.13438`
- Authors: Yanjia Sun , Sifan Liu , Jie Shao
- Score: 8
- Link: https://arxiv.org/abs/2606.13438
- PDF: https://arxiv.org/pdf/2606.13438
- Subjects: Information Retrieval (cs.IR)
- Reason: The paper proposes a robust RAG method using cross-query consistency, which is directly relevant to retrieval-augmented generation for astronomical literature review and data analysis.

Short digest:
This paper addresses the problem of hallucinations in retrieval-augmented generation (RAG) systems. It proposes a cross-query consistency hypothesis: correct answers maintain high confidence across semantically equivalent queries, while hallucinations do not. The method rewrites the original question into diverse but meaning-preserving queries and selects answers based on confidence stability across contexts. This is highly relevant to astronomy because RAG systems can be used for literature review, data analysis, and scientific workflows. The method could be applied to build robust AI agents that retrieve and synthesize astronomical knowledge from papers and databases. A key caveat is that the method requires a way to generate diverse but meaning-preserving queries, which may need domain-specific rewriting models.

Full-text inspection checklist:
- Check if the paper provides a method for generating diverse queries that is domain-agnostic or adaptable to astronomy.
- Look for the specific metrics used to evaluate cross-query consistency and how they are computed.

## 4. A Three-Layer Framework for AI in Scientific Discovery

- arXiv ID: `2606.13566`
- Authors: Guojun Liao
- Score: 8
- Link: https://arxiv.org/abs/2606.13566
- PDF: https://arxiv.org/pdf/2606.13566
- Subjects: Artificial Intelligence (cs.AI)
- Reason: Proposes a three-layer framework for AI in scientific discovery, focusing on model formation through qualitative reasoning, which directly addresses how AI can aid conceptual breakthroughs in astronomy.

Short digest:
This paper addresses the limitation of current AI in scientific discovery, which focuses on search and execution but neglects model formation. It proposes a three-layer framework: Layer 1 (search/retrieval), Layer 2 (model formation through qualitative reasoning), and Layer 3 (execution/optimization). The main claim is that Layer 2 is the most important and least developed, involving recognizing when a framework is inadequate and finding solutions in unexpected fields. This matters for astronomy because it provides a roadmap for developing AI that can help form new theoretical models for high-redshift galaxies, AGN, or little red dots. An astronomer could imagine using such an AI to identify missing conceptual objects in current galaxy formation models. A caveat is that the paper is conceptual and does not provide a concrete implementation or code.

Full-text inspection checklist:
- Check if the paper provides any concrete methodology for implementing Layer 2 reasoning, or if it remains purely conceptual.
- Look for case studies that are relevant to astronomy or physics to assess transferability.
- Check whether the paper discusses how to integrate Layer 2 with existing LLM-based search and retrieval tools.

## 5. Recursive Agent Harnesses

- arXiv ID: `2606.13643`
- Authors: Elias Lumer , Sahil Sen , Kevin Paul , Vamse Kumar Subbiah
- Score: 8
- Link: https://arxiv.org/abs/2606.13643
- PDF: https://arxiv.org/pdf/2606.13643
- Subjects: Computation and Language (cs.CL)
- Reason: Recursive agent harnesses with filesystem tools and code execution are directly applicable to building research agents for automated scientific discovery in astronomy.

Short digest:
This paper introduces Recursive Agent Harnesses (RAH), where a parent agent spawns subagent harnesses with filesystem tools, code execution, and planning to solve long-context reasoning tasks. The key idea is harness recursion: the recursive unit is a full agent environment, not just a model call. For astronomy, this could be used to build a research agent that spawns subagents to analyze different parts of a large dataset (e.g., multiple JWST fields) or to run parallel simulations. The paper shows significant improvements on long-context coding tasks, but the tasks are synthetic and not scientific. An astronomer would need to design appropriate subagent tasks and tool environments for their workflow.

Full-text inspection checklist:
- Check whether the paper provides details on the filesystem and code execution tools available to subagents; these would need to be adapted for astronomical data analysis.
- Look for the specific planning mechanism used by the parent agent to decompose tasks; see if it is learned or rule-based.
- See if the framework is released as open-source code that can be extended with custom tools.
