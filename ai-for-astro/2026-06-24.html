S1-Omni-Image: A Unified Model for Scientific Image Understanding, Generation, and Editing

Qingxiao Li , Zikai Wang , Qingli Wang , Nan Xu

arXiv PDF

Short Digest

This paper aims to create a unified model that can understand, generate, and edit scientific images, going beyond general-purpose image models. The core idea is a 'think-before-generate' paradigm: the model first produces a reasoning trace and textual answer, then uses those hidden states to condition image generation or editing. This is highly relevant for astronomy because it could enable tasks like generating synthetic JWST images, editing astronomical images for artifact removal, or performing segmentation of galaxies and AGN. An astronomer could imagine using this model to generate realistic mock images of high-redshift galaxies for training classifiers, or to edit multi-band images to highlight specific features. A key caveat is that the model is trained on SciGenEdit, a dataset of scientific illustrations and medical/geographic images, not astronomical data, so its performance on JWST or HST images is unknown and would require fine-tuning or domain adaptation.

Reason

This paper presents a unified multimodal model for scientific image understanding, generation, and editing, which directly aligns with interests in multimodal models for astronomy and automated scientific discovery.

Full-Text Inspection Checklist

  • Check whether the model's generation and editing capabilities are demonstrated on astronomical images or only on medical/geographic/illustration data.
  • Look for evaluation metrics on scientific image understanding tasks that are analogous to astronomy (e.g., segmentation, super-resolution).
  • Examine the training dataset composition to see if any astronomy-specific images (e.g., from telescopes) are included.
  • Check if the model supports multi-turn editing that could be applied to iterative analysis of astronomical data.
Abstract

We present S1-Omni-Image, an open-weight unified multimodal model for scientific image understanding, generation, and editing. Unlike general-purpose image generation models, scientific image tasks require not only high-fidelity synthesis, but also robust understanding of scientific semantics, structural relations, domain knowledge, and task intent. To this end, S1-Omni-Image builds on the scientific multimodal reasoning backbone S1-VL-32B and couples its understanding capability with an image generation module under a unified think-before-generate paradigm. Given a user instruction, the model first produces a task-oriented reasoning trace, a textual answer, and a task special token; their hidden states are then injected into the generation module to condition image generation or editing. S1-Omni-Image supports scientific image understanding, generation, and editing in a unified framework. For generation, it focuses on scientific illustrations and text rendering, including logical diagrams, relational comparisons, data charts, and realistic scientific visualizations. For editing, it casts segmentation and other domain-specific vision tasks as native image editing problems, enabling multi-turn illustration editing, medical and geographic image segmentation, medical image translation, and scientific image super-resolution. We construct SciGenEdit, a 314K-sample training dataset, and release the model weights, inference code, and SciGenEdit-10K. Experiments show that S1-Omni-Image substantially improves scientific image generation and editing while preserving the scientific image understanding capability inherited from S1-VL-32B. It outperforms open-source models on GenExam and TechImage-Bench, achieves state-of-the-art results on four editing benchmarks including MSD, cigRockSEM, SynthRAD2025, and IXI, and maintains stable performance on scientific image understanding evaluations.

Maestro Order: A Model-Agnostic Orchestration Harness

Hidayet Aksu

arXiv PDF

Short Digest

This paper presents Maestro Order, a framework for composing unreliable LLM solvers into reliable systems using decomposition, ensembling, verification, and recursion. It uses a budget-aware controller to allocate compute efficiently. For astronomy, this could be used to build a reliable research agent that performs multi-step analysis (e.g., querying a database, running a model, checking results) with built-in verification. A concrete workflow would be an agent that retrieves JWST spectra, fits them, and verifies the fit quality before reporting results. A key caveat is that the evaluation is done via simulation, not on real-world tasks, so the practical performance on astronomical workflows is unknown.

Reason

Directly addresses building reliable LLM-based systems using verification and orchestration, which is highly relevant for developing research agents for astronomy.

Full-Text Inspection Checklist

  • Check the verifier ensemble design: what types of verifiers are used and how are they combined?
  • Look for the budget-aware controller algorithm and how it decides where to allocate compute.
  • Examine the failure modes section for guidance on how to avoid verifier gaming or error compounding in a scientific context.
Abstract

A single forward pass of a capable model is a fast, fluent, and unreliable problem-solver: it is right often enough to be useful and wrong often enough to be dangerous; in language models, such confident errors are known as hallucinations. We present Maestro Order, a model-agnostic orchestration harness that turns unreliable solvers into reliable problem-solving systems by composing them according to four structural primitives (decompose, ensemble, verify, and recurse) and a budget-aware controller that decides where to spend compute. The harness treats any model as a black-box base solver behind a uniform interface, layers a verifier ensemble whose discrimination is measured online, and allocates verification and voting to the stages with the highest marginal reliability per unit cost. We give the architecture, the message and state schema, the controller algorithm, and the engineering that makes it deterministic, observable, and fault-tolerant. We then specify an evaluation methodology (reliability at fixed cost, coverage, calibration, and ablations) and report results from a faithful Monte Carlo simulation of the harness over a parameterized solver/verifier model. The simulation reproduces the predicted laws quantitatively: verification amplifies reliability geometrically (e.g. $0.55\to0.98$ with two gates, $\to0.999$ with four), voting helps only above chance and is limited by shared errors, and a budget-aware controller reaches a target reliability at a small fraction of the cost of voting alone by selecting the cheapest mechanism for each regime. We close with failure modes (verifier gaming, correlated errors, and decomposition error compounding) and concrete guidance: build robust checkers, diversify solvers, and let the controller put compute where the information is.

Learning to Trigger: Reinforcement Learning at the Large Hadron Collider

Zixin Ding , Shaghayegh Emam , Giovanna Salvi , Cecilia Tosciri , Abhijith Gandrakota , Jennifer Ngadiuba , Nhan Tran , Christian Herwig , David W. Miller , Yuxin Chen

arXiv PDF

Short Digest

This paper uses reinforcement learning to dynamically tune trigger thresholds at the Large Hadron Collider, maximizing signal efficiency while maintaining a target background rate. The agent is trained on simulated data and successfully transferred to real collision data. For astronomy, this approach could be used to optimize real-time filtering of transient alerts from surveys like Rubin/LSST or to prioritize JWST observations. A concrete workflow would be an RL agent that adjusts the threshold for a transient alert system to maximize the detection of rare events (e.g., supernovae) while avoiding too many false positives. A key caveat is that the method is demonstrated on a specific LHC trigger system, and adapting it to astronomical surveys would require a realistic simulator of the survey's data stream.

Reason

Directly applies reinforcement learning to a real-time scientific data filtering problem (LHC trigger), which is highly relevant for real-time analysis in astronomy (e.g., transient alerts, survey data processing).

Full-Text Inspection Checklist

  • Check the state representation: what features of the data stream are used as input to the RL agent?
  • Look for the reward function design: how is signal efficiency balanced against background rate?
  • Examine the transfer learning results from simulation to real data: how much fine-tuning was needed?
Abstract

High-throughput scientific facilities such as the Large Hadron Collider depend on real-time event filtering (\textit{triggering}) under tight constraints on bandwidth, latency, and storage. In practice, trigger menus are largely static and hand-tuned and can become suboptimal as detector conditions, pileup, and background composition drift over time. We cast online threshold tuning as a sequential decision-making problem: a reinforcement learning agent ingests streaming summaries of recent rates and signal-sensitive features and updates trigger thresholds to maximize signal efficiency while tracking a target background rate within a tolerance band. We adapt Group-Filtered Policy Optimization (GFPO) to streaming control and introduce two variants (GFPO-F, GFPO-FR) that enforce background rate feasibility during training. On a benchmark that emulates realistic collider operation, we study two representative triggers: a total transverse energy ($H_{T}$) trigger sensitive to pileup variation, and an anomaly-detection (AD) trigger based on reconstruction loss for rare or non-standard signatures. On Monte Carlo streams, our agent increases the fraction of in-tolerance time intervals by 48\% ($H_T$) and 28\% (AD), with a cumulative gain of up to 2\% in signal efficiency on those in-tolerance intervals. Transferring from simulation to \emph{real} collision data (CMS Run 283408), the same agent, without fine-tuning, achieves a 56\% ($H_T$) and 28\% (AD) in-tolerance improvement over baselines, with further signal-efficiency gain on both triggers. To our knowledge, this is the \emph{first} demonstration of RL-based trigger control on real Large Hadron Collider collision data. Code is available at this https URL \_LHC.

Agon: An Autonomous Large-Scale Omnidisciplinary Research System Built on Prompt Economy

Youran Sun , Xingyu Ren , Chugang Yi , Jiaxuan Guo , Kejia Zhang , Jianda Du , Haizhao Yang

arXiv PDF

Short Digest

This paper presents Agon, an autonomous research orchestrator that uses large language models to scale research production. The system is built on a 'Prompt Economy' where LLMs generate and validate research artifacts, with human oversight for final judgments. For astronomy, this could automate literature review, hypothesis generation, and even data analysis pipelines. One could imagine using Agon to automatically search for new high-redshift galaxy candidates in JWST data, generate SED fitting scripts, or cross-match catalogs. A key limitation is that the system has been tested across domains but not specifically on astronomy, and its reliability for complex scientific reasoning remains unproven. The paper also catalogs failure modes that require human intervention, which is important to understand before deployment.

Reason

Autonomous research system using LLMs, directly relevant to automated scientific discovery for astronomy.

Full-Text Inspection Checklist

  • Look for examples of scientific workflows the system has successfully completed, especially any involving data analysis or simulation.
  • Check the taxonomy of failures: how many are fixable by the system vs. requiring human judgment?
  • Examine the Prompt Economy loop details: how are prompts generated and validated for scientific accuracy?
Abstract

Large language models are making research production scalable, shifting the bottleneck from producing artifacts to judging claims. We present \textsc{Agon}, a research orchestrator that validates what can be checked inside the workflow and leaves the remaining judgments to human scientists. \textsc{Agon} is built on six design principles: Prompt Economy, Future-Facing, Minimal Prompts, OmniDisciplinary, Massive Parallelism, and Zero-Code. We ran \textsc{Agon} across domains for 444 iterations of Prompt Economy loops, using only small starting topics and no human-written experimental code. These deployments demonstrate scalability while exposing new classes of failure. We organize these failures into a taxonomy along severity, fixability, visibility, and capability locus. The taxonomy separates failures the loops can see and fix from those that require human judgment. Together, these results show that \textsc{Agon} is pushing research toward a new paradigm: machine scales, human steers.

LemonHarness Technical Report

Kailong Ren , Fubo Sun , Jiachen Liu , Liu Yang , Zimo Yin , Jiaying Li , Congli Yin , Ming He , Yu Huo , Jiawei Liu , Zeping Chen , Yubin Huangfu , Ronghua Li , Yixuan Wu , Xing Su , Yanzhi Xu , Likang Wu , Hongke Zhao , Lei Zhang , Xiaohui Geng , Jianping Fan

arXiv PDF

Short Digest

This paper presents LemonHarness, an execution framework for long-horizon LLM agents that constrains state-changing operations within a defined workspace and integrates model invocation, tool execution, and rule knowledge. It introduces a reusable rule knowledge base and time-aware execution to help agents balance exploration and validation. For astronomy, this framework could be used to build an agent that autonomously runs a data reduction pipeline (e.g., for JWST), manages file outputs, and adapts to time constraints. A concrete workflow could involve an agent that downloads JWST data, runs calibration steps, performs source extraction, and validates results, all within a controlled workspace. The main caveat is that the framework is demonstrated on a software engineering benchmark (Terminal-Bench), not on scientific tasks, so its effectiveness for astronomy-specific workflows needs testing.

Reason

Directly relevant to LLM agents for long-horizon tasks, which could be applied to automated scientific workflows in astronomy, such as data reduction, analysis pipelines, or literature review.

Full-Text Inspection Checklist

  • Check if the framework supports custom tool definitions (e.g., for astronomical software like astropy, drizzle, or SExtractor).
  • Look for details on how the rule knowledge base is constructed and whether it can be populated with domain-specific rules (e.g., data quality checks for JWST).
  • Assess the time-aware execution mechanism: can it handle long-running astronomical tasks (e.g., SED fitting, MCMC sampling) that may take hours?
Abstract

As large language model (LLM) agents are applied to longer tasks, they increasingly modify workspace state across multiple rounds of iteration. However, agents typically observe only tool outputs and log fragments, while the actual state changes occur in the file system. Without explicit workspace boundaries, state-changing operations such as file writes and temporary artifact generation may scatter changes across paths. Over time, these weakly constrained changes accumulate, making states such as modified files difficult to track. This paper presents LemonHarness, an integrated execution framework for long-horizon agents. LemonHarness establishes an explicit execution boundary by constraining state-changing operations within a clearly defined workspace and bringing model invocation, tool execution, and rule knowledge within a single controlled boundary. State-changing operations, including file writes, dependency installation, and temporary artifact creation, are executed through structured tool interfaces, with execution feedback recorded as observations available to subsequent model decisions. The system also introduces a reusable rule knowledge base, which turns recurring execution rules and acceptance criteria into runtime knowledge. LemonHarness further adds a time-aware execution mechanism that exposes elapsed and remaining budget to the model, so it can rebalance exploration, implementation, and validation effort as time pressure shifts and avoid timeouts from long waits or excessive verification. On Terminal-Bench 2.0, LemonHarness_GPT-5.3-CodeX reached 84.49% accuracy over 445 trials; pairing the same framework with the stronger GPT-5.5 backbone raised the average accuracy to 86.52% across five jobs. The results suggest that a unified runtime boundary, callable rule knowledge, and time-aware execution can improve the stability of long-horizon agent execution.

Solving Inverse Problems of Chaotic Systems with Bidirectional Conditional Flow Matching

Peiyan Hu , Jian Zhang , Jiashu Pan , Ruiqi Feng , Tao Zhang , Zhi-Ming Ma , Yuan-Sen Ting , Gongjie Li , Tailin Wu

arXiv PDF

Short Digest

This paper tackles the problem of inferring initial conditions from final states in chaotic systems, which is an ill-posed inverse problem. The main AI idea is Bidirectional Conditional Flow Matching (Bi-CFM), which learns bidirectional mappings between distributions of initial and final states using a generative flow matching approach. For systems with conservation laws, they extend it to Conservation-constrained Bi-CFM (CBi-CFM). This matters for astronomy because it is applied to the three-body planet-planet scattering problem in planetary dynamics and to real observations of globular clusters, which are collisional million-body systems evolved over 10 Gyr. A concrete workflow would be using CBi-CFM to infer the initial orbital configurations of planetary systems from their present-day architectures, or to reconstruct the initial conditions of globular clusters from current observations. A key caveat is that the method requires training on simulations of the specific chaotic system, so it may not generalize to systems without sufficient simulation data or where conservation laws are not well-understood.

Reason

The paper directly addresses inverse problems in chaotic systems with applications to planetary dynamics and globular clusters, which are core astrophysical problems. The method uses flow matching, a generative AI technique, and is evaluated on real astronomical data.

Full-Text Inspection Checklist

  • Check the evaluation on real globular cluster observations: what data was used and how were initial conditions validated?
  • Look for the conservation error metrics on the three-body problem to assess how well physical laws are respected.
  • Examine the distribution-level metrics (e.g., MMD, Wasserstein distance) to see how well the method captures the full stochasticity of chaotic evolution.
  • Check the computational cost: the paper claims two orders of magnitude speedup over baselines, verify what baselines and hardware were used.
Abstract

Modeling chaotic systems is crucial yet challenging. Inverse problems in chaotic dynamics, namely inferring initial conditions from final states, remain largely unsolved because of ill-posedness, non-uniqueness, instability, and potentially chaotic time-reverse dynamics. We address this open problem with Bidirectional Conditional Flow Matching (Bi-CFM), which learns bidirectional mappings between distributions of initial and final states to capture the stochasticity of chaotic evolution and mitigate exponential error accumulation over time. Furthermore, for systems with conservation laws, we extend it to Conservation-constrained Bi-CFM (CBi-CFM). Across the classic Lorenz, Circuit, and high-dimensional Lorenz 96 systems, Bi-CFM improves five distribution-level metrics over baselines while achieving a speedup of more than two orders of magnitude. In the three-body planet-planet scattering problem in planetary dynamics, CBi-CFM better respects conservation laws, with conservation errors comparable to those of the ground truth. Finally, on real observations of globular clusters, collisional million-body systems shaped by $\sim 10^{10}$ years (10 Gyr) of evolution, our method represents an advance in accuracy, establishing a scalable route to solving inverse problems of long-timescale real-world chaotic dynamics.

OpenThoughts-Agent: Data Recipes for Agentic Models

Negin Raoof , Richard Zhuang , Marianna Nezhurina , Etash Guha , Atula Tejaswi , Ryan Marten , Charlie F. Ruan , Tyler Griggs , Alexander Glenn Shaw , Hritik Bansal , E. Kelly Buchanan , Artem Gazizov , Reinhard Heckel , Chinmay Hegde , Sankalp Jajee , Daanish Khazi , Emmanouil Koukoumidis , Xiangyi Li , Hange Liu , Shlok Natarajan , Harsh Raj , Nicholas Roberts , Ethan Shen , Nishad Singhi , Michael Siu , Ashima Suvarna , Hanwen Xing , Patrick Yubeaton , Robert Zhang , Leon Liangyu Chen , Xiaokun Chen , Steven Dillmann , Saadia Gabriel , Xunyi Jiang , Anurag Kashyap , Boxuan Li , Yein Park , Minh Pham , Sujay Sanghavi , Lin Shi , Ke Sun , Yixin Wang , Zhiwei Xu , Erica Zhang , Siyan Zhao , Wanjia Zhao , Jenia Jitsev , Alex Dimakis , Benjamin Feuer , Ludwig Schmidt

arXiv PDF

Short Digest

This paper asks how to curate training data for broadly capable agentic language models that generalize across diverse tasks. It conducts over 100 controlled ablation experiments to build a data curation pipeline and assembles a 100K-example training set that improves average accuracy across seven agentic benchmarks by 3.9 percentage points over existing open models. For astronomy, this pipeline could be used to train agents that perform literature review, data analysis, or code generation for JWST or survey data, as the method is task-agnostic and focuses on diversity and scaling. The fully open release of training sets, pipeline, and models means an astronomer could adapt the recipes to create an agent specialized for astronomical workflows, though the current benchmarks are not astronomy-specific. A key caveat is that the paper does not test on scientific or domain-specific tasks, so transferability to astronomy remains to be demonstrated.

Reason

This paper presents a fully open data curation pipeline for training agentic language models, which directly aligns with the interest in LLM agents for scientific workflows and automated discovery.

Full-Text Inspection Checklist

  • Check the list of task sources used in the pipeline to see if they include scientific or data-analysis tasks, or only software engineering and web tasks.
  • Look for details on the ablation experiments that identify which task sources and diversity measures are most important for generalization.
  • Examine the released training data and pipeline code to assess how easily it can be adapted to astronomy-specific agent tasks.
Abstract

Agentic language models dramatically expand the applications of AI yet little is publicly known about how to curate training data for broadly capable agents. Existing open efforts such as SWE-Smith, SERA, and Nemotron-Terminal typically target a single benchmark, leaving open the question of how to train models that generalize across diverse agentic tasks. The OpenThoughts-Agent (OT-Agent) project addresses this gap with a fully open data curation pipeline for training agentic models. We conduct more than 100 controlled ablation experiments to systematically investigate each stage of the pipeline, yielding insights on the importance of task sources and diversity. We then assemble a training set of 100K examples from our pipeline and fine-tune Qwen3-32B on this dataset, which yields an average accuracy of 44.8% across seven agentic benchmarks and a 3.9 percentage point improvement over the strongest existing open data agentic model (Nemotron-Terminal-32B, 40.9%). Moreover, our training data exhibits strong scaling properties, outperforming alternative open datasets at every training set size in compute-controlled comparisons. We publicly release our training sets, data pipeline, experimental data, and models at this http URL to support future open research on agentic model training.
