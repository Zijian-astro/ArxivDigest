EurekAgent: Agent Environment Engineering is All You Need For Autonomous Scientific Discovery

Amy Xin , Jiening Siow , Junjie Wang , Zijun Yao , Fanjin Zhang , Jian Song , Lei Hou , Juanzi Li

arXiv PDF

Short Digest

This paper argues that the bottleneck for autonomous scientific discovery is no longer agent workflows but the design of agent environments—the resources, constraints, and interfaces that shape agent behavior. It presents EurekAgent, a system that engineers environments along four dimensions: permissions, artifacts, budget, and human-in-the-loop. For astronomy, this could be used to build a research agent that autonomously analyzes JWST data, runs SED fitting, and searches for high-redshift galaxies. The system achieves state-of-the-art results on math and ML tasks with very low API cost. An astronomer would need to design the appropriate environment (tools, data access, evaluation metrics) for their specific discovery task.

Reason

Directly addresses autonomous scientific discovery with LLM agents, including environment engineering for reliable research agents, which is highly relevant for astronomy.

Full-Text Inspection Checklist

  • Check whether the paper provides a detailed description of the artifact engineering (filesystem, Git) and how it supports systematic experimentation.
  • Look for the specific permissions engineering; see how it prevents reward hacking and ensures safe execution.
  • See if the human-in-the-loop engineering is practical for a busy astronomer; does it require constant monitoring or just occasional intervention?
Abstract

LLM-based agents have shown increasing potential in automating scientific discovery. Given an optimizable metric and an execution environment, they can propose, validate, and iterate scientific solutions, and have produced results that outperform human-designed approaches. As model capabilities continue to improve, we argue that the bottleneck for autonomous scientific discovery is shifting from prescribing agent workflows to designing agent environments: the resources, constraints, and interfaces that shape agent behavior. We frame this as environment engineering: building environments that amplify productive behaviors, such as open-ended exploration, systematic artifact management, and inter-agent collaboration, while suppressing harmful behaviors, such as reward hacking and high-friction human oversight. We present EurekAgent, an environment-engineered agent system for metric-driven autonomous scientific discovery. EurekAgent engineers the environment along four dimensions: permissions engineering for bounded agent execution and isolated evaluation; artifact engineering for filesystem and Git-based collaboration; budget engineering for budget-aware exploration; and human-in-the-loop engineering for easy human supervision and intervention. EurekAgent sets new state-of-the-art results on multiple mathematics, kernel engineering, and machine learning tasks, including new state-of-the-art 26-circle packing results discovered with less than $11 in total API cost. We open-source our code and results, and call for environment engineering as a core research direction for developing reliable autonomous research agents.

Benchmarking AI Agents for Addressing Scientific Challenges Across Scales

Tianyu Liu , Allen Xin Wang , Antonia Panescu , Lisa Xinyi Chen , Wenxin Long , Xinyu Wei , Yueqian Jing , Ziyao Zeng , Jihang Chen , Sihan Jiang , Ziqing Wang , Siyi Gu , Siyu Chen , Xinyang Hu , Haoran Shao , Leqi Xu , Wangjie Zheng , Zhiyuan Cao , Ada Fang , Botao Yu , Kunyang Sun , Rex Ying , Arman Cohan , Qingyu Chen , Lingzhou Xue , Kaize Ding , Yuanqi Du , Wengong Jin , Zhuoran Yang , Marinka Zitnik , James Zou , Hua Xu , Hongyu Zhao

arXiv PDF

Short Digest

This paper asks how well current AI agents perform on real-world scientific research tasks. The authors introduce SciAgentArena, a benchmark of ~200 tasks with stepwise verification and an interactive environment. They find that agents handle well-specified data-analysis workflows but struggle with generating novel insights and open-ended research. For astronomy, this suggests current agents could assist with routine data reduction or classification but not yet autonomous discovery. A concrete workflow might be using an agent to run a standard SED-fitting pipeline on a JWST catalog. A key caveat is that the benchmark tasks are drawn from multiple domains, so astronomy-specific performance is not isolated.

Reason

Directly evaluates AI agents for scientific discovery, which is a core interest. The benchmark includes tasks across domains and could inform how to build agents for astronomy workflows.

Full-Text Inspection Checklist

  • Check which scientific domains are included and whether astronomy tasks are present
  • Look for examples of well-specified vs. open-ended tasks to gauge transferability to JWST analysis
  • Examine the evaluation criteria for data-analysis workflows to see if they match typical astronomy pipelines
Abstract

AI agents are increasingly being developed to accelerate scientific discovery, yet their practical capabilities in real research settings remain poorly understood. Existing benchmarks for AI agents rarely capture the complexity, heterogeneity, and extended reasoning required by scientific work, whereas benchmarks for scientific tasks often reduce research to static, direct problems and provide limited support for interactive evaluation. Here, we introduce SciAgentArena, a systematic benchmark for evaluating AI agents in real-world scientific research scenarios drawn from emerging needs across multiple domains. SciAgentArena comprises approximately 200 tasks with stepwise verification and an interactive, agent-agnostic environment for assessing diverse AI agents. Using this benchmark, we find that current agents can contribute effectively to well-specified data-analysis workflows, particularly when the task structure and evaluation criteria are clear. However, their performance remains uneven across scientific contexts: agents struggle to generate genuinely novel insights, sustain self-directed exploration, and formulate robust solutions for open-ended research questions. We further characterize common failure modes across agents and identify opportunities for improving their reliability, autonomy, and scientific reasoning. Together, SciAgentArena provides a practical framework for measuring progress in AI agents for science and for guiding the design of future agents capable of addressing complex scientific challenges. CQC-RAG: Robust Retrieval-Augmented Generation via Cross-Query Consistency

Yanjia Sun , Sifan Liu , Jie Shao

arXiv PDF

Short Digest

This paper addresses the problem of hallucinations in retrieval-augmented generation (RAG) systems. It proposes a cross-query consistency hypothesis: correct answers maintain high confidence across semantically equivalent queries, while hallucinations do not. The method rewrites the original question into diverse but meaning-preserving queries and selects answers based on confidence stability across contexts. This is highly relevant to astronomy because RAG systems can be used for literature review, data analysis, and scientific workflows. The method could be applied to build robust AI agents that retrieve and synthesize astronomical knowledge from papers and databases. A key caveat is that the method requires a way to generate diverse but meaning-preserving queries, which may need domain-specific rewriting models.

Reason

The paper proposes a robust RAG method using cross-query consistency, which is directly relevant to retrieval-augmented generation for astronomical literature review and data analysis.

Full-Text Inspection Checklist

  • Check if the paper provides a method for generating diverse queries that is domain-agnostic or adaptable to astronomy.
  • Look for the specific metrics used to evaluate cross-query consistency and how they are computed.
Abstract

Retrieval-Augmented Generation (RAG) has become a common approach for improving the factuality of Large Language Models (LLMs), yet its reliability remains highly sensitive to how external evidence is retrieved and used. Semantically equivalent queries with different syntactic forms may lead to different retrieval results, while irrelevant or misleading documents can further induce hallucinated answers. Existing multi-path reasoning methods improve robustness by sampling multiple candidate answers and applying voting- or confidence-based selection, but they still face two limitations: diversity is often injected through uncontrollable decoding randomness, and answer evaluation is usually confined to a single query-induced evidence view. To address these limitations, we propose a Cross-Query Consistency Hypothesis: correct answers tend to maintain high confidence across semantically equivalent but syntactically diverse queries, whereas noise-induced hallucinations exhibit unstable confidence under such query variations. Based on this hypothesis, we introduce CQC-RAG, a framework that co-designs query-level diversity injection with cross-query consistency evaluation. CQC-RAG rewrites the original question into diverse but meaning-preserving queries, reranks a shared document pool to construct query-conditioned reasoning contexts, applies an evidence-grounded protocol to extract answer-evidence pairs and selects answers according to their confidence stability across these contexts. This design enables self-evaluation without external supervision and does not rely on expanded retrieval coverage. Experiments on four open-domain question answering benchmarks show that CQC-RAG outperforms the strongest previous multi-query baseline by +4.76 pp EM on TriviaQA and +9.12 pp EM on MuSiQue, validating the effectiveness of cross-query consistency for filtering noise-induced hallucinations.

A Three-Layer Framework for AI in Scientific Discovery

Guojun Liao

arXiv PDF

Short Digest

This paper addresses the limitation of current AI in scientific discovery, which focuses on search and execution but neglects model formation. It proposes a three-layer framework: Layer 1 (search/retrieval), Layer 2 (model formation through qualitative reasoning), and Layer 3 (execution/optimization). The main claim is that Layer 2 is the most important and least developed, involving recognizing when a framework is inadequate and finding solutions in unexpected fields. This matters for astronomy because it provides a roadmap for developing AI that can help form new theoretical models for high-redshift galaxies, AGN, or little red dots. An astronomer could imagine using such an AI to identify missing conceptual objects in current galaxy formation models. A caveat is that the paper is conceptual and does not provide a concrete implementation or code.

Reason

Proposes a three-layer framework for AI in scientific discovery, focusing on model formation through qualitative reasoning, which directly addresses how AI can aid conceptual breakthroughs in astronomy.

Full-Text Inspection Checklist

  • Check if the paper provides any concrete methodology for implementing Layer 2 reasoning, or if it remains purely conceptual.
  • Look for case studies that are relevant to astronomy or physics to assess transferability.
  • Check whether the paper discusses how to integrate Layer 2 with existing LLM-based search and retrieval tools.
Abstract

Current discussions of AI in scientific discovery are often dominated by two visible capabilities: search over existing knowledge and execution through optimization, simulation, and automation. Both are important, but neither fully captures the central act of discovery: the formation and evolution of models. This paper proposes a three-layer view of AI in discovery. Layer 1 is search and retrieval by large language models. Layer 2, as the main innovation of this paper, is model formation through qualitative reasoning: the capacity to recognize when a current framework is structurally inadequate and to understand the problem within a broader representational space, not through trial and error, but through structural insight into what is missing and where it can be found. Layer 3 is execution, optimization, and refinement. The main claim is that Layer 2 is both the most important and the least developed. Search without model formation remains confined to inherited frameworks, while execution without conceptual revision only amplifies an existing formulation. We illustrate Layer 2 reasoning through three case studies: S. S. Chern's intrinsic proof of the Gauss-Bonnet theorem, the resolution of the Nesterov Accelerated Gradient convergence problem via Lyapunov functions, and the autonomous disproof of the Erdos unit distance conjecture by OpenAI in 2026. Each case exhibits the same structural signature: a framework that had become inadequate, a missing conceptual object, and a resolution found in an unexpected neighboring field.

Recursive Agent Harnesses

Elias Lumer , Sahil Sen , Kevin Paul , Vamse Kumar Subbiah

arXiv PDF

Short Digest

This paper introduces Recursive Agent Harnesses (RAH), where a parent agent spawns subagent harnesses with filesystem tools, code execution, and planning to solve long-context reasoning tasks. The key idea is harness recursion: the recursive unit is a full agent environment, not just a model call. For astronomy, this could be used to build a research agent that spawns subagents to analyze different parts of a large dataset (e.g., multiple JWST fields) or to run parallel simulations. The paper shows significant improvements on long-context coding tasks, but the tasks are synthetic and not scientific. An astronomer would need to design appropriate subagent tasks and tool environments for their workflow.

Reason

Recursive agent harnesses with filesystem tools and code execution are directly applicable to building research agents for automated scientific discovery in astronomy.

Full-Text Inspection Checklist

  • Check whether the paper provides details on the filesystem and code execution tools available to subagents; these would need to be adapted for astronomical data analysis.
  • Look for the specific planning mechanism used by the parent agent to decompose tasks; see if it is learned or rule-based.
  • See if the framework is released as open-source code that can be extended with custom tools.
Abstract

Recursive language models (RLMs) showed that recursion over model calls is an effective strategy for long-context reasoning, and production coding agents have begun to write code that spawns subagents at scale, most recently in Anthropic's dynamic workflows. We name and study the pattern between these two lines of work, where the recursive unit is a full agent harness with filesystem tools, code execution, and planning rather than a model call with no tools. We call this the Recursive Agent Harness (RAH) and frame it as harness recursion, the code-first extension to the model recursion of RLMs. A parent agent generates and runs an executable script that spawns subagent harnesses in parallel for fine-grained workloads and uses structured function calls for small subtasks. We provide a controlled evaluation on long-context reasoning. With the backbone held fixed at GPT-5 to match the published Codex and RLM baselines, RAH improves the Codex coding-agent baseline from 71.75% to 81.36% on Oolong-Synthetic (199 samples, 13 context-length buckets up to 4M tokens), a gain attributable to the harness rather than the model. With a stronger backbone, Claude Sonnet 4.5, the same design reaches 89.77%.
