- Subjects: Astrophysics of Galaxies (astro-ph.GA)
- Reason: This paper uses machine learning to identify massive quiescent galaxies at high redshift in COSMOS2025, directly relevant to high-redshift galaxy studies and ML applications.

Short digest:
The central question is identifying massive quiescent galaxies at 2.5<z<5 using a machine learning classifier. The main result is that the classifier finds 2.6 times more candidates than SED-fitting, suggesting SED-fitting misses transitional galaxies. This matters for my work because it demonstrates a ML approach to improve quiescent galaxy selection at high redshift.

## 2. When X-ray Features Hurt: Label Noise and Luminosity Overlap in Machine Learning Classification of AGN and Star-forming Galaxies

- arXiv ID: `2607.13233`
- Authors: Jaymin Ding
- Score: 7
- Link: https://arxiv.org/abs/2607.13233
- PDF: https://arxiv.org/pdf/2607.13233
- Subjects: Astrophysics of Galaxies (astro-ph.GA) ; Instrumentation and Methods for Astrophysics (astro-ph.IM)
- Reason: This paper investigates label noise and luminosity overlap in ML classification of AGN and star-forming galaxies, which is directly relevant to AGN selection and classification methods.

Short digest:
The central question is why adding an X-ray feature decreased AGN/SFG classification accuracy. The main result is that the discrepancy is due to label noise near the BPT demarcation line and X-ray luminosity overlap. This matters for my work because it highlights pitfalls in using X-ray data for AGN classification in optically-selected samples.

Full-text inspection checklist:
- Check the X-ray luminosity distributions for AGN and SFGs and the overlap near 10^42 erg/s.
- Look for the permutation importance analysis showing the X-ray feature harms predictions.
- Examine the misclassification clustering near the Kewley demarcation curve.
